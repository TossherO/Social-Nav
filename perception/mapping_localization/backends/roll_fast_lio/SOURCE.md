# ROLL＋FAST-LIO 来源

来自用户提供的 `hys_server_migration_20261012.zip`，归档内
`hys/mapping_migration/mapping_ws/src/roll`、`fastlio-loc` 的当前适配源码。
此前从实际轮椅镜像 `nav_gpu_backup:latest` 迁出，镜像摘要
`sha256:78a40441acc6a9c89a260086ef16b60ca94ed233640aaa4961f8e6883c7d7ff6`。

当前副本采用原设备的输入时间处理、地图保存保护和关键帧缓存；本项目追加
采集时间绑定的定位健康消息、连续局部位姿与地图位姿分离、统一TF发布职责。
当前新增FAST-LIO局部里程计任务：只维护滚动匹配地图，直接发布绑定当前匹配质量的
定位消息与`odom → rslidar`，不启动ROLL或导出地图。显示输出按订阅和任务开启，
关闭未使用的地图显示线程；ROLL逐帧文件仅在显式保留明细时写入。
人工初值确认、选点前输入分阶段启动及重新定位时的轨迹隔离由本项目适配实现。
只读有图定位增加按位移后台构建局部特征、隔离重定位代次、复用配准KD树及有界关键帧缓存预算，
任务入口按后端队列进度收尾，溢出丢帧明确失败；未指定可信区域时匹配比例接受判据沿用原实现。
可选地图可信区域门控由本项目实现：区域外冻结先验修正并保留局部里程计，返图时检查
配准质量、修正幅度及连续候选一致性后恢复；区域绑定地图资产，不裁剪原始地图。
ROLL配准保持跨迭代投影与末次位姿更新，有图定位的退化特征值阈值独立配置。
配准工作区及最近邻检索缓冲跨帧／跨点复用；显示地图构建和回环ICP基于快照运行，
提交时检查地图修正是否已使快照失效。可选分段计时在任务结束时合并，不影响默认产物保留策略。
建图回环按关键帧顺序补查，使用该帧时间和历史点云范围；详细模式可记录候选至约束入图的各阶段。
特征配准使用独立线程缓冲并按扫描顺序汇总，LM矩阵存储跨迭代复用；
只读定位在初值确认阶段准备子图，等待后台更新后再次检查位移预算。
显式静止伪IMU实验为定位来源增加`_stationary_assumption`标识；位姿和健康仍由原配准过程计算。
小关键帧的坐标变换使用串行循环，避免为少量点重复创建并行任务；建图仍沿用原有全量降采样。
原归档和其中冻结源码不修改；许可证分别见两个源码目录的LICENSE。

本项目独立实现了共用的静止／运动初始化：陀螺去旋转畸变、短时点云ICP、
几何位姿与IMU积分对齐、非零初速与有限偏置估计，以及人工首帧起点传播。
从较短窗口开始检查，结合线性化重力方向敏感度及持续稳定区间决定是否结束，质量不足时继续滚动积累。
思路参考[Dynamic Initialization for LiDAR-inertial SLAM](https://arxiv.org/abs/2504.01451)，
未引入或宣称复现上游D-LI-Init代码；当前短时里程计、质量门限与轴向加速度偏置模型均为本项目实现。
历史初始化仅在显式关闭自适应配置时使用；外参、时间偏移和完整IMU标定未自动求解。

多雷达FAST_LIO_MULTI、旧版本快照和完整历史日志保留在原归档。
