# 项目文档写作示例

以下示例用于说明如何把技术内容写清楚。“历史写法”保留重写前的表达，不表示当前文档仍有这些问题；“推荐写法”和保留示例展示可以借鉴的表达方式。改写重点是减少读者需要自行推断的内容，不要求字数减少。

来源链接指向相关主题，正文可能已更新。这份示例不维护当前功能、配置或验证状态，也不随每次实现变化更新。实际写作仍查项目正文，不要把例句中的实现或状态复制到其他模块。

## 例一：把压缩的内存说明展开

来源：[接口约定中的直接运行时](../../../../docs/接口约定.md#感知导航直接运行时)。

历史写法：

> 主机数组由memfd共享槽封存，描述包含形状、类型、偏移、槽代次和内容摘要；接收端只读映射，所有读者释放前不能复用槽。

推荐写法：

> 主机数组保存在 memfd 共享内存槽中，发布后保持只读。描述信息记录数组的形状、类型、偏移、槽代次和内容摘要。
>
> 接收进程通过只读映射访问数组。所有读取方释放引用后，这个槽位才能用于下一批数据。

这里补全了“谁读取、什么时候能覆盖”的关系，保留 memfd、描述字段和内存复用条件。不能再压缩成“通过共享内存提高效率”，因为这会丢失所有权约束，并新增未经这段文字证明的性能结论。

## 例二：把流程缩写写成读者能跟随的过程

来源：[Agent 技术实现中的总体路线](../../../../docs/decision/Agent技术实现.md#总体路线)。

历史写法：

> **合成反馈闭环**：API计划→工具→项目参考规划／DWA／独立安全→差速积分运动反馈→阶段推进。仿真没有真实RGB渲染，不能用录包图像冒充动作后的新视图。
>
> **真实观察影子循环**：已有场景或runtime观察→API审查→读取已有视图／澄清／受限重规划。只提交影子目标或取消，不具备真实执行完成权。

推荐写法：

> 在合成反馈仿真中，Agent 先通过 API 生成计划，再调用工具进入项目的参考规划、DWA 控制和独立安全检查。仿真器用差速运动积分生成运动反馈，执行内核根据反馈推进任务阶段。这个仿真没有真实 RGB 渲染，因此录包图像不能用来表示动作后的新视图。
>
> 在真实观察的影子运行中，Agent 读取已有场景或 runtime 提供的观察，通过 API 审查后，可以读取已有视图、请求用户澄清，或在既定限制内重新规划。“影子”表示系统只提交目标建议和取消请求，轮椅不执行这些建议，也不能据此报告真实任务已经完成。

两段各解释一种运行方式，并把适用限制放在对应流程旁。“影子”通过系统实际做什么、轮椅是否执行来解释，读者无需自行猜测。技术名称仍然保留；后续需要解释 DWA 时，链接控制专题即可，不必在这里插入算法推导。

## 例三：把多个有效性条件分开

来源：[定位失效时的处理](../../../../docs/接口约定.md#定位失效时的处理)。以下摘录省略原文链接。

历史写法：

> 检测只接受与观察同一时钟、采集时刻不晚于观察且未过期的定位；有界等待及年龄阈值由 inference.json 维护，节点处理见检测与跟踪。

推荐写法：

> 检测使用的定位结果必须同时满足以下条件：
>
> - 与当前观察使用同一时钟域。
> - 定位的采集时刻不晚于该观察。
> - 定位结果尚未过期。
>
> 等待时间上限和允许的定位年龄由 inference.json 维护，节点处理见检测与跟踪。

实际写回时保留原文的配置和专题链接。这种列表用于让调用者逐项核对条件；只有一个简单条件时，无需拆成列表。不能改为“检测使用最新定位”，因为最新结果可能来自观察之后。

## 保留例一：事件和行为已经一一对应

来源：[Agent 任务执行与反馈](../../../../docs/decision/Agent技术实现.md#任务执行与反馈)，摘录两行：

| 情况 | 执行内核的行为 |
|---|---|
| 收到导航 ACK，即请求接收确认 | 保留活动调用，等待执行反馈，不立即推进步骤。 |
| 等待用户继续 | 先确认停车，再等候属于该任务的 `continue` 事件。影子状态不能证明已经停车。 |

这里的表格便于直接查找行为。ACK 在首次出现处已有解释，动作和等待条件也已写明。否定句说明请求确认与执行反馈的区别，并保留停车确认的限制，删掉会改变语义；无需为了润色改动表格结构。

## 保留例二：精确字段需要保留术语和数值

来源：[环境栅格属性定义](../../../../docs/perception/技术实现-环境地图与场景表示.md#属性定义与作用)，摘录一个字段：

| 属性（类型／单位） | 含义与计算 | 主要作用 |
|---|---|---|
| `occupancy`（int8） | `-1/0/100`＝未知／有证据空闲／占据；由命中、射线及高度覆盖共同决定 | 基础障碍表达、显示及后续规划输入 |

字段表中的类型、编码和计算依据是调用者需要的内容。斜杠在这里表示逐项对应，含义明确。不能用“记录障碍情况”替代，也不能为了消除符号而改变字段值。
