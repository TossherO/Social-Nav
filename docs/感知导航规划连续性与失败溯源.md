# 感知导航规划连续性与失败溯源

本专题定位参考路径中断、DWA无候选和异常绕行。当前开发输入是10月20日第二段有图与无图路线。算法机制见[路径规划](navigation/技术实现-路径规划.md)与[局部控制](navigation/技术实现-局部控制与安全.md)，地图逐格原因见[地图诊断](感知导航规划诊断与改进.md)。

## 当前结论与证据范围

最近完整路线对照为[地面历史修复后的常规配置](../outputs/navigation/ground_history_recovery/report.md)和[激进配置复测](../outputs/navigation/aggressive_profile_recheck/report.md)，均从包头处理第二段148.40秒。运行采用Xeon W-2265、RTX 3090、单线程数字库、1倍速并开启规划及时序记录，具体配置与源码摘要保存在对应报告中。

| 指标 | 常规配置 | 激进配置 |
|---|---:|---:|
| 参考可用周期占比 | 84.3% | 83.0% |
| DWA候选周期占比 | 33.0% | 70.8% |
| 对应安全允许周期占比 | 31.4% | 69.5% |
| 无合规速度周期 | 659 | 43 |

日常默认仍为常规配置。激进参数来自录制运动估计，尚不是实测车辆限值。两次异步回放的取帧、查询和目标更新有差异，不能把收益归给某个单独参数。bag不会响应速度建议，参考可用、DWA候选、安全允许和真实到达必须分别报告；RViz冻结预览也不能替代完整回放或实机验收。

### 输入时效与参考持续性

关联在场景封存前重新核对，并保留原匹配时间；封存后不回填。先区分生产耗时、交付等待和重复消费过期，再决定优化哪个阶段，不能刷新源时间掩盖延迟。机制见[局部定位与先验关联](perception/技术实现-建图与定位.md#局部定位与先验关联)。

普通滚动目标更新仍重新建立参考。若要利用旧几何，必须重新对应新请求并通过当前检查；真正取消、换图、定位重置和迟到结果仍须撤销。

### 地图受阻与运动约束

参考查询与DWA可能使用不同时间的位姿，足迹覆盖的格子也可能不同。诊断应使用各自实际消费的导航图、位姿和余量，分别统计未知、占据、图外及只触及余量的格子。RGB只用于理解场景。安全胶囊没有完整地面与覆盖字段，不能单靠恢复字段传输补齐静态未知；当前证据路径见[局部证据进入全局参考](navigation/技术实现-路径规划.md#局部证据进入全局参考)。

DWA在初速无法及时降至目标限速时可能只剩制动与速度恢复候选。此前扩大采样没有改善固定输入结果，暂不再盲目增加候选。应区分采样遗漏、当前无法安全停车和bag未执行建议，不能裁剪观测初速来通过检查。

### 当前目标处理与剩余限制

当前使用端点预检查和有限较近中间目标，候选共享搜索预算。切换产生新目标修订，停车终点不替换；候选耗尽后由参考进程重试当前目标。该策略接入显式路线回放，其他在线任务入口仍需明确接入，见[分段目标回放](navigation/技术实现-任务与路线.md#录制行程的分段目标回放)。历史短路径和制动反例保存在[历史报告](../outputs/navigation/history/report.md)，不再作为当前统计重复维护。

| 要回答的问题 | 复用的记录 | 必要时补充 |

启用诊断会增加复制与写入，应报告记录是否完整及丢弃数量。HTML缺少原消费地图时明确使用静态背景；安全结果按原候选身份和复核时间对应，不能提前显示较晚的允许。

## 最短的后续溯源路径

1. 从上述保留运行中选一个失败和一个相邻正常案例，先检查已有记录，不重跑检测与定位来重复计数。
2. 固定输入验证地图、搜索或控制机制。地图历史规则改变时，从会话起点连续重建，不能直接跳到失败时刻后声称恢复了原历史。
3. 只有排队或时效问题才做同负载短回放。固定输入不能证明实时调度改善；需要验证减速后的恢复时使用反馈仿真。
4. 相关模块检查通过后，集中跑一次受影响片段。只有需要整段收益或后段出现新疑点时，才扩展到当前148.40秒路线；无需反复重跑旧367秒场景。

## 解决判据

修复须连接触发条件、代码分支、同输入对照与恢复条件，并保留应拒绝的反例。报告全部路线周期及可比输入子集，说明缺失区间；频率不恒定时按时间戳统计空窗。

- 连续性：有效输入恢复后的等待、最长无参考时长、目标取消与无进展，不能靠取消更多目标提高可用率。
- 地图：阻挡格来源与恢复证据，不以自由格增加代替准确性。
- DWA：按初速和限速原因分组，分别报告候选生成、独立安全和完整制动检查。
- 时效与性能：区分测量到发布、发布到首次消费、提前退出和实际计算，异步阶段P95不相加。
- 搜索与绕行：在相同地图和运动约束下比较路径长度、偏移及实际起点接入。
