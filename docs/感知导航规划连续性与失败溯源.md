# 感知导航规划连续性与失败溯源

本专题处理实时导航中的参考路径中断、DWA无候选和不合理绕行，以`2026-10-29-15-59-09.bag`为开发样例。目标是找到最早阻止规划的条件，区分环境证据不足、任务状态变化、计算延迟和运动约束，再用少量固定输入验证修复。

已完成参考连续性修复、异步关联交付和参考查询复用已有局部自由证据。用户确认轮椅支持倒车后，规划、DWA及独立安全已允许倒车，最新固定查询、60秒回放和两例反馈仿真见[倒车验证](../outputs/navigation/reverse_navigation/report.md)。[参考证据一致性验证](../outputs/navigation/reference_start_consistency/report.md)与[后续核查](../outputs/navigation/remaining_planning_diagnosis/report.md)保留启用倒车前的输入和诊断，后者中的目标调整尚未实施。[关联交付验证](../outputs/navigation/association_delivery/report.md)保留前一阶段时序证据；原96秒[图层与曲线HTML](../outputs/navigation/planning_continuity/review.html)保留首轮诊断，不代表当前回放。本页维护当前结论和下一步溯源方法；其他地图问题见[地图诊断](感知导航规划诊断与改进.md)，整体验收见[共同清单](感知导航待办与数据采集.md#规划持续可用性专题)。

## 当前结论与证据范围

原[367秒时间轴](../outputs/navigation/planning_timeline/wheelchair_20261029_floor1/review.html)记录了用户观察到的失败，但没有保存逐帧地图与规划曲线。首轮溯源从会话起点连续处理0–96秒，并保存实际消费的导航图、原参考、DWA结果、查询输入、足迹详情和速度窗口；后续60秒对照沿用这些诊断字段，因而可以继续核对具体成因。

已修复短暂输入过期后的两处问题：同一路线段保留任务，避免因测量时间短暂不合格取消目标；恢复输入后重新校验保留参考，恢复显示与当前状态。真实取消、关联丢失和定位重置仍按原语义处理。当前机制分别见[任务与路线](navigation/技术实现-任务与路线.md#录制行程的分段目标回放)和[路径规划](navigation/技术实现-路径规划.md#参考生命周期与局部段)。

关联交付阶段的60秒对照中，关联过期拒绝由183次降至25次，对应状态时长由18.41秒降至2.44秒；参考状态可用率由30.3%升至52.6%，DWA生成率由27.8%升至46.8%。该阶段只记录标量计时，不能与后续完整图层归档负载混用性能数字。

参考证据一致性阶段的60秒对照保持局部地图原规则，参考查询临时使用已有局部自由证据。参考可用率从44.6%升至53.8%，DWA生成率从39.3%升至48.4%；两次全局起点未知失败消失，局部起点受阻等待仍为11.80→12.00秒。该报告的周期数含运行收尾，固定19份查询中成功数由12增至15，原12份成功均保留。

启用倒车后，同一19份查询成功数由15增至16。查询9–12从约7.85米绕行缩短为1.59–1.64米，查询13生成0.329米倒车路径。新的60秒影子回放严格按源时间0–60秒统计：DWA生成周期从267/545增至279/546，参考可用周期从297/545增至304/546；35次提议为倒车，独立安全记录44次倒车放行，后者可重复复核同一提议。局部未知与占据等待合计仍约12秒。两例带执行器延迟的合成反馈仿真完成了直线和圆弧倒车停车。

连续回放的实际处理扫描和查询时机不同，不能把所有时长变化直接归因于单个改动；固定输入用于验证几何原因。倒车也使剩余失败查询的搜索量增加，新的参考查询平均累计CPU时间由173增至247毫秒。输入、硬件、有效配置和摘要集中在各验证报告中。

参考可用、DWA生成、安全允许和实际到达是不同状态。bag沿原录制轨迹前进，不响应算法建议；两例合成反馈仿真不代表真实场景。当前未执行倒车改动后的完整367秒、二楼或实机验收。

### 输入时效与参考持续性

当前取消与恢复逻辑、已完成关联的及时交付均已修复，地图或关联过期仍会阻止提议。分段计时发现的原因见[时效检查](../outputs/navigation/association_timing/report.md)，实际优化与保留范围见[交付验证](../outputs/navigation/association_delivery/report.md)。匹配完成至上下文接收与检查的P50从60.37降至1.49毫秒，关联在控制入口的年龄P50从337.57降至232.76毫秒。

新关联在场景封存前重新检查确认、可信覆盖和生命周期，并保留原匹配时间；失效结果同样会传到建图端。没有对应更新时继续使用原扫描关联及其原时效，已经封存的场景不回填。机制由[建图与定位](perception/技术实现-建图与定位.md#局部定位与先验关联)和[接口约定](接口约定.md#感知导航直接运行时)维护。

允许新地图触发控制的试验缩短了首次消费等待，却增加了反馈年龄与有目标无候选时长，已恢复原节拍。后续应结合感知、地图长尾和首次消费时机继续优化，不能只用调用次数或更短的单项等待认定改善。更多周期进入真实DWA计算后，检测和地图耗时也可能受到负载影响，本轮不构成所有模块提速的结论。

普通滚动目标更新仍会重新建立参考。只有证明旧几何在新请求中可以合法接入并通过当前检查后，才考虑将其作为新查询的引导；不能把旧目标的结果改写摘要后当作新目标结果。

倒车前保存运行中，56次关联过期的关联年龄与场景年龄一致，中位数0.423秒；对应场景首次消费年龄中位数0.283秒，交付至首次消费等待中位数36毫秒。不能将其都解释为匹配耗时。下一步保留控制节拍和源时间，核对场景完成、交付和重复消费，分类处理退避；不直接延长0.4秒关联期限。

### 地图受阻与运动约束

固定原基线查询1、8揭示了两次起点检查使用不同证据：局部起点各115格均自由，全局足迹却分别含1格和2格未知。三个静态未知格的高度覆盖均为16/17，每格相交的四个局部格均为原始自由，非静态派生自由。因此问题是已有局部证据没有进入全局查询，而不是这些位置仍需降低局部自由门限。

安全胶囊缺完整地面和覆盖字段，会使`PriorRevisions`报告`evidence_layers_unavailable`；但该修订器即使取得完整字段也只清除旧占据，不补旧未知。恢复字段传输不能单独解决这里的问题。当前`Planner._query()`通过[临时参考工作图](navigation/技术实现-路径规划.md#局部证据进入全局参考)补齐这条证据路径，只接受原始局部与核验导航图均自由的完整相交范围，保留静态占据、原资产与来源时间。`ReferenceRuntime.tick()`的3秒失败退避保持原样。

倒车前保存的22份受阻完整场景中，3份处于楼层参考预热，1份尚未通过先验楼层确认，10份已启用静态支持，8份没有有效关联。这是约2Hz保存样本，不能代替所有受阻周期的根因分布。具体静态未知、高差和普通命中分类由[地图诊断](感知导航规划诊断与改进.md#近场未知与人物历史恢复)维护。室外无关联区域不能直接沿用室内静态地图，开头的未知也不能统一归因于行人历史残留。

参考入口使用场景观察时的位姿，DWA使用当前反馈位姿，两次足迹检查可能覆盖不同格子。诊断须使用各自实际消费的导航图、位姿和余量，分别统计未知、占据、图外，以及只触及余量的格子。RGB用于理解场景，不能单独证明某格可通行。

DWA在当前速度不能及时降至目标限速时可能只剩制动与速度恢复候选。本轮扩大候选没有改善固定输入结果，因此仍保持原规则。要区分采样不足和初态已无法安全停车，不能裁剪估计速度，也不能把bag未执行减速后的连续失败解释为闭环控制必然失败。

原约40.82秒的绕圈曾做仅前进的无障碍敏感性检查：1.17米搜索半径下，360个终点朝向取样的最短连接约7.17米；0.8米半径下约1.26米。倒车验证表明，无需缩小半径即可显著缩短这组路径。当前XY路线目标没有硬性终点yaw，不能把终点直线进场参数直接认定为绕行原因。有限采样和有界搜索也不构成连续空间最优性的证明。

### 拟议的目标处理方案

倒车前四份失败查询的[几何对照图](../outputs/navigation/remaining_planning_diagnosis/query_diagnosis.png)表明，查询14和19的目标中心虽自由，完整车体却不可能放入。允许倒车不能消除这一限制。原仅前进诊断中，沿路线缩短前视分别可得到约1.49米和2.01米的自由路径，查询19的2.5米前视点则产生8.11米绕行。这些候选尚未按当前倒车策略重选，目标排序仍应同时考虑路线进展、路径长度和偏离，不能只选最远可达点。

建议先提前拒绝已能证明足迹不可行的目标，再由路线层显式产生少量滚动目标候选，共享规划预算，并保留新目标修订与参考来源核对。只调整已授权路线上的中间目标，不替换用户指定的停车终点。原查询15的0.5米短段仍须检查当前初速下的完整制动。查询13已有倒车解，后续应区分确需返回的停车目标与已通过的中间目标，避免不必要地倒回旧点；这一语义调整已不再是恢复该查询几何可行性的前提。路线通过不表示真实任务完成，楼层切换也不能绕过外部确认。

这套目标方案尚未接入运行。最小验收先复用剩余三份失败与当前16份成功查询，再测试超越目标、横向偏离、定位重置、停车终点和短路径制动，最后集中执行一次60秒回放。增加搜索预算、细化全部状态或放宽地图不能替代目标可行性处理。

## 已有诊断与仍需补充的字段

`--record-planning`默认关闭。显式启用后保持正常异步地图调度，后台使用有界队列写入，每周期记录实际控制对应关系，约2Hz保存场景，并额外保留查询输入。命令和记录完整性检查由[操作速查](感知导航操作速查.md#结果回看)维护。图层和参考按摘要去重，后台持有封存数据的引用，不读取已经复用的共享槽。

仅诊断时序时使用独立的`--trace-timing`，记录匹配、检测、地图发布与控制消费的标量事件，退出时写盘。它不自动启用图层归档；容量、丢弃与实际执行范围须随结果检查。

| 要回答的问题 | 已有记录 | 仍需补充或进一步分析 |
|---|---|---|
| 失败是否来自一次上游事件？ | 周期号、目标修订、路线与参考事件、场景和结果摘要。 | 将恢复时间与引起中断的具体事件连接，区分正常目标推进和暂时输入失效。 |
| 数据在哪一段变旧？ | 原始测量时间、匹配提交至读取、关联选择、检测、地图计算和发布，以及控制首次与重复消费的单调时刻。 | 继续分析场景长尾；安全进程内部接收与首次复核、原生匹配长尾的逐次子阶段尚未拆开。 |
| 哪些格子挡住车体？ | 参考足迹分类与格子数量、对应原始和导航图层、地面和支持状态。 | 将具体阻挡格与静态地面、投影重叠、普通命中和人物证据逐项对应；DWA反馈位姿另查。 |
| 为什么参考未就绪？ | 工作进程是否就绪或忙碌、起点是否受阻、重试剩余时间、查询输入及原始结果。 | 分别归因于未提交、计算中、退避、过期或目标变化，不重复计算同一次中断。 |
| 为什么候选退化？ | 观测和传播后的初速、实际控制间隔、各限速值、速度窗口、候选及拒绝计数。 | 必要时仅对选定失败保存逐候选轨迹和首个拒绝位置，避免大量无用归档。 |
| 绕行从哪里出现？ | 实际参考和已通过认证的DWA曲线、查询图与参数、地图坐标变换。 | 固定查询检查自由空间运动约束、端点及当前占据，再区分目标表达和搜索问题。 |

诊断是可选负载，须报告复制、写入与丢弃情况。限量记录缺少某个周期的地图时，HTML明确退回静态背景，不能用相邻图或重新计算结果冒充原消费图。安全结果按`trajectory_binding`对应候选，并保留独立复核时刻，不将较晚的允许提前显示。

每类故障配一个相邻正常案例。时间问题使用原速率短回放；固定输入只能验证算法机制，不能证明实时排队已经改善。地图状态规则一旦改变，须从会话起点连续重建，或使用完整且经过验证的状态检查点；不能直接从83秒启动后宣称恢复了原历史。

按以下条件选择改进，而不是同时调整多个阈值：

| 证据成立的条件 | 对应改进方向 | 验证重点 |
|---|---|---|
| 地图发布后仍有可消除的等待 | 优化最新场景交接和消费者调度。若限制主要在生产端，再处理对应计算阶段。 | 同负载下首次消费年龄降低，反馈时效和原源时间仍准确。 |
| 阻挡格来自地面或投影的实现缺陷 | 只修正已定位的一处地面、投影或历史恢复机制。 | 固定输入逐格解释变化，墙柱、新障碍及静止人物反例继续受保护。 |
| 旧参考在新滚动目标中可合法接入 | 将旧几何作为新查询引导，重新对应请求并认证。 | 真正取消、换图、定位重置和迟到结果仍正确撤销。 |
| 有合规动作被采样遗漏 | 再尝试有针对性的候选补充。 | 在真实失败输入上新增通过动作，且完整扫掠、人物及制动检查仍通过。 |
| 搜索失败源于重复准备或连接限制 | 优化已经测得的阶段，或修正目标选择。 | 保持同一输入及运动约束，预算耗尽不被解释为绝对无路。 |
| 当前运动模型不符合实车能力 | 用已确认的测量更新模型。 | 不仅匹配bag，也验证真实速度、转弯和制动能力；当前没有此项实机结论。 |

相关模块检查通过后，再集中进行一次受影响短段的集成回放。只有后段出现新问题，或准备报告整段收益时，才扩展到0–367秒；不为每个补丁反复跑整包。验证减速后是否能恢复导航时使用会响应提议的反馈仿真，实机另按[接入要求](感知导航待办与数据采集.md#实车接入前)进行。

## 解决判据

每项修复须连接原始触发条件、代码分支、同输入对照和恢复条件。减少拒绝次数或增加候选本身不足以证明改善，原本应拒绝的反例也须保持正确。

- 连续性报告目标取消、参考重建、有效输入恢复后的等待，以及连续无参考时长；不能通过取消更多目标提高可用率。
- 时间报告测量到发布、发布到首次消费的延迟，区分过旧和未来时间，异步阶段P95不相加。
- 地图报告阻挡格的分类和恢复证据，不以自由格增加替代准确性。
- DWA按初速和限速原因分组，分别报告候选生成与独立安全复核。
- 搜索与绕行在相同地图和运动约束下比较长度、路线偏移、实际起点接入及完整扫掠。

对照同时报告原定路线时间窗内的全部周期和可比输入子集，并说明缺失区间。控制频率不恒定时，空窗按时间戳计算，不能直接用帧数乘0.1秒。当前优先验证目标可行性与通过判定，再核对局部格的地面和静态支持来源，最后处理分类退避与交付尾延迟；车辆能力无法从日志可靠确认的部分再提交人工核实。
