# 感知导航规划诊断与改进

本文只维护地图可通行性的剩余问题。当前地图使用静态自由背景和独立人物圆；地面变化未确认时暂停使用相关自由证据，保留历史，待地面恢复后重新使用。实现见[环境地图专题](perception/技术实现-环境地图与场景表示.md)，参考与DWA的中断另见[失败溯源](感知导航规划连续性与失败溯源.md)。

## 当前处理顺序

| 优先级 | 尚存问题 | 下一步检查 |
|---|---|---|
| 1 | 无图段的局部未知、地面确认期间的短时中断 | 核查10月20日第二段约87、124、130秒的缺口及89秒附近占据，区分观测不足、地面冲突和真实障碍。 |
| 2 | 旧先验内部的静态高差与自由缺口 | 复用10月29日起点足迹的逐格证据，分别处理邻格高差和11个静态未知格，不与无图段混算。 |
| 3 | 人物归属与背景恢复缺少独立反例验收 | 检查靠墙、门框、静止人物、漏检、稀疏肢体，以及新障碍长期被遮挡。 |
| 4 | 单平面与静态背景的适用范围 | 验证坡面、台阶、多片地面、换层、定位高度误差、地图过时和关联重获。 |

## 近场未知与人物历史恢复

### 无图段：仍有局部缺口

[地面历史修复](../outputs/navigation/ground_history_recovery/report.md)以常规运动配置从包头处理10月20日第二段148.40秒，其中约42.50–132.30秒离开地图关联范围，局部定位持续有效。剩余50个参考起点受阻周期中，31个为未知、19个为占据；重点位置列在上表。

误删地面历史的问题已修复，但地面确认期间仍整体暂停局部地面自由支持。54.00秒和80.40秒的异常分别暂停约1.6秒、1.2秒。后续应检查能否缩小暂停影响，同时保持新障碍有效，不能把全部剩余未知解释为行人残留或期限届满。暂停规则见[地面跟踪](perception/技术实现-环境地图与场景表示.md#固定安装传感器的地面跟踪)。

### 旧先验：高差与未知需要分别处理

[起点足迹归因](../outputs/navigation/start_footprint_audit/report.md)对10月29日60秒运行中保留完整地图的21份场景进行逐格检查，覆盖112个受阻周期中的47个。215个未知格次中，111个因静态邻格高差超过15厘米被拒绝，88个涉及11个静态未知格，16个位于可信覆盖之外；另有4个普通占据格次，没有当前人物圆造成的起点阻挡。格次包含重复位置，比例只适用于该保存子集。

首个足迹的32格未知均受静态邻格高差限制，已不是在线地面预热。只在地图副本上将容差放宽到20厘米，14份启动足迹仅2份通过；取消检查也仅4份通过。中位数地面重导出没有让这14份足迹通过，并使14个原自由格次变为非自由。下一步比较稳健地面参考与同层静态自由支持，不能据这些试验直接取消高差保护。

这些未知格均缺原始局部地面支持，高度覆盖率为0，单降局部概率或覆盖阈值无效。11个静态未知格中已有10格做过历史射线审计，只有2格达到16/17层自由，应继续核对末次命中与后续射线。冻结先验可能使用同格最后一个内点，当前静态导出使用逐格中位数，局部地面仍按点序保留最后一个内点；来源差异见[先验支撑审计](../outputs/navigation/history/reports/prior_support_audit.md)。稳定后的单点高度不能单独证明场景变化。

### 人物与普通障碍：仍缺独立精度证据

[65帧三维动态审查](../outputs/navigation/person_segmentation_review/report.md)已得到用户对所选片段的认可，暂不扩张人物点删除范围。该审查没有逐点真值，仍需独立验证近墙连通、静止人物和漏分。已成功移交人物圆的回波不用于生成额外占据，射线仍止于原回波，人物后方的未知不能因此变为自由；人物圆继续参与当前接触与时序检查，身份失配退回静态圆。

确认人物前或归属失败时产生的普通占据不会随人物框整体删除。上述4个占据格次涉及3个位置，保留期限为2秒；命中帧没有人物检测，已有轨迹均为预测态，尚不能认定是已识别人点的残留。只有核对同帧回波、取得归属依据后，才考虑清除历史普通命中。

背景普通命中到期后可以恢复静态自由，目前没有稳定新障碍的永久冲突记录，也没有人物离开的独立观测证明。高度分类优先使用在线局部地面，缺失时退回所选静态地面。因此长期遮挡、地图变化和复杂地形仍需反例验收。

## 验证与关联专题

修改地图状态规则后，应从会话起点连续重建，或使用完整且经过验证的状态检查点。逐格说明改变依据，同时检查墙柱、新障碍、负障碍、静止人物与换层；不能以自由格增多代替准确性。

启动净空与自车区域仍需要已确认的实体几何和外参，不能用历史导航余量或录制轨迹替代环境证据。车辆测量、部署负载及独立验收统一见[共同清单](感知导航待办与数据采集.md)，当前性能依据见[推理速度](感知导航推理速度.md)。当前结果不证明实机导航已验收；旧四场景页面和已撤回方案只作[历史来源](archive/感知导航地图诊断历史.md)。
