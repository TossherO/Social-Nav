# 停车预测模型归档

此前 DWA 对候选预测之外还检查假设的完整停车轨迹。模型先传播反馈年龄和执行延迟，再按反应预算保持运动，最后用运动配置中的加速度乘以制动系数积分到零速。终点与转弯限速也使用制动能力和距离计算。

真实执行的独立安全还按声明的平面速度、角速度和停稳时间上界构造扩展响应范围，检查整个范围内的地图和人物。旧模型的反应时间、执行器延迟、制动系数及停稳时间是试验假设，并非对本车物理能力的证明。11 月 9 日现场记录中，扩展范围曾导致大量授权拒绝。

此前的合成反例表明，实际响应比名义加速快或减速更慢时，车体可能超出名义预测轨迹；旧响应范围用于覆盖声明速度和停稳时间上界内的这类差异。该反例不是本车实测，移除范围后这种偏差也不再由范围检查覆盖。

原始实现保存在 Git 提交 `3d2381702a1a` 的 `navigation/safety/guard.py`、`navigation/safety/response.py`、`navigation/control/dwa.py` 及其对应配置中。当前实现改为有限时域运动检查，具体范围与限制见[局部控制与安全](../navigation/技术实现-局部控制与安全.md)。
