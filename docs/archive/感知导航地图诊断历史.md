# 感知导航地图与控制诊断历史

本页只记录已停止维护或未采用的方法及其取舍。当前实现见[环境地图专题](../perception/技术实现-环境地图与场景表示.md)，尚存问题见[规划诊断](../感知导航规划诊断与改进.md)，性能见[推理速度](../感知导航推理速度.md)。归档内容不能作为当前运行参数或验收结论。

| 历史方法 | 基本思路 | 停止使用或未采用的原因 |
|---|---|---|
| 在线地面再次确认静态自由 | 等待局部平面预热，再以严格高度一致性和确认面积允许先验支持。 | 启动关联高差会撤回大面积已建图自由。当前直接检查所选静态背景、有效关联及整格支持，在线地面只参与当前障碍高度分类。 |
| 人物点与动态圆重复占据 | 人物点仍写入短期占据，预测视图只在历史自由及所有速度有效时移除。 | 逐格地面缺失易漏分人物，留下普通占据；当前同帧可靠点逐人交给动态圆，旧式短期路径仅用于无法完成移交的输入。 |
| 持久自由背景与逐体素冲突 | 缓存跨窗口自由证据，逐个记录障碍命中，取得后续自由射线后才清除冲突；后来增加背景优先到期恢复。 | 状态与CPU工作量较大。当前采用有界二维静态支持及独立命中期限。 |
| 人物历史归属与离开清除 | 把命中关联到跟踪身份，确认同一人物离开后撤销原命中。 | 依赖稳定身份和可靠地面，增加跨帧状态与失效处理；当前不以检测消失推断自由。 |
| 孤立未知小孔填补 | 在已有自由包围、局部高差和障碍约束下推断小片未知。 | 引入未直接观测的自由依据；当前没有通用未知填补。 |
| 启动净空与自车区域 | 使用有来源的实体轮廓或人工确认区域补充初始空闲。 | 本车实体几何和外参未确认，未投入当前运行；所需实测仍列在待办中。 |
| 分区高程 | 局部多片拟合、地面连接和误差随时间传播，以适应坡面和台阶。 | 缺少独立地形与车辆能力验收，当前保留单平面地面跟踪。 |
| CPU融合独立进程及回传 | 将持久背景融合移出主进程，通过共享槽交接，再上传导航层。 | 当前二维支持直接在GPU生成，省去该进程及回传路径。 |
| 按消费者范围裁剪 | 尝试按需距离场、近场投影与端点上传裁剪。 | 同输入地图结果一致，但没有明确总耗时收益，未采用。DWA与安全裁剪尚未测试。 |
| 静态`people`与`consistent`模式 | 前者单独按人物过滤，后者要求所有障碍取得多次非人物支持。 | 当前保留几何反证复核，可选叠加同源人物过滤；缺射线时只允许不制造自由的端点导出。 |

自由高度覆盖曾按浮点累加，现已改为整数计数；人物占据期限经过同源开发场景对照后采用0.2秒，并保留普通命中的独立期限保护。较短期限不等于人物已经离开，原审查也不是独立检测或通行真值。

早期地图恢复、轻量二维支持、消费者范围试验和地面批量计算分别保留在[策略恢复](../../outputs/runtime/map_strategy_restore/report.md)、[二维支持结果](../../outputs/navigation/map_lightweight_support/)、[范围实验](../../outputs/navigation/history/reports/map_consumer_regions.md)和[地面优化报告](../../outputs/navigation/ground_fit_performance/report.md)。旧镜像的算法来源见[旧系统评估](导航旧系统资料评估.md)。

历史源码已从活跃模块和测试中清理，删除前的精确源码及本次检查保留在[清理记录](../../outputs/navigation/history/reports/current_algorithm_cleanup.md)。原始审查HTML、人工意见、静态资产、冻结输入和性能日志保持原来源，不改摘要。旧派生算法的文件可读取原始数组，但不能作为当前规划已经核验的输入。

2026-11-05另试验近车1.5米内的封闭未知小孔插值，要求自由包围、面积不超过0.25平方米，并保留占据与端点保护。该方法使局部受阻减少，但60秒回放的DWA生成率未提高，地图平均耗时增加4.47毫秒，已完整撤回。原试验结论保存在[试验报告](../../outputs/navigation/history/reports/near_field_clearance.md)，中间HTML已清理，精确源码并入[撤回源码包](../../outputs/navigation/history/diagnostics.zip)。后续逐格核查发现，局部已有自由未进入全局参考查询是另一项独立缺陷；当前机制由[路径规划](../navigation/技术实现-路径规划.md#局部证据进入全局参考)维护。

## 已移除的导航分支

在线地面确认的启动归因、逐地图关联细化和静态包重建证据分别保存在[启动诊断](../../outputs/navigation/history/reports/startup_floor_attribution.md)、[关联细化试验](../../outputs/navigation/history/reports/ground_refinement_validation.md)与[先验审计](../../outputs/navigation/history/reports/prior_support_audit.md)。细化增加关键路径耗时且未解除完整足迹阻挡，没有投入默认实现。新背景和人物策略的短段结果集中见[验证报告](../../outputs/navigation/background_person_navigation/report.md)，不替换上述历史来源。

2026-11-06撤回离线静态导出的附加自由恢复：该实现记录末次物理命中、后续独立自由桶，并以整列检查约束补回的高度证据。历史771扫描只使58个未知格转为空闲，未解除重点启动足迹，60秒回放无净收益。原报告、地图和HTML保留在[静态恢复试验](../../outputs/navigation/static_free_recovery/report.md)；当前保留原累计概率与几何反证，不通过省略恢复保护条件来扩大自由区。

同次简化删除路线层的阻塞候选集合及端点恢复后重开批次机制，保留端点预检查、有限较近目标、共享搜索预算和请求核对。候选耗尽后由原参考进程重试当前目标。当时启动时差估计仍为显式初始化，默认仅复用已验证且会话相符的配置；随后[零偏移对照](../../outputs/perception/time_offset_comparison/report.md)显示二层恢复片段的差异较小，因此移除了启动估计器、预热包装及策略选项，改为零偏移默认，保留离线标定工具和显式固定补偿。原源码与历史配置保存在对照目录的`retired_startup_sources.zip`，不作为当前入口。倒车、原地旋转、关联交付与参考连续性修复继续保留。

| 历史方法 | 基本思路 | 当前处理 |
|---|---|---|
| TEB 与带时轨迹修正 | 优化几何与时间，再由另一套跟踪器计算速度；全局、局部和后台修正各有工作进程。 | 删除求解器、适配源码、三进程运行时、`trajectory/stream` 命令和专用测试。当前只生成 Hybrid A* 空间参考，再由 DWA 直接选速度。 |
| 滚动轨迹与时间重参数化 | 沿参考生成可达短轨迹，再调整时间和末速。 | 删除该候选分支；当前 DWA 仍使用共享的运动积分、SE(2) 插值、转弯约束和完整制动检查。 |
| 人物可达圆膨胀 | 将协方差、加速度界和未知速度半径加到人物包络。 | 删除 `bounded` 预测及参数。当前为确定性世界系匀速预测，圆半径至少覆盖配置身体半径及本帧归属点，未知速度保留为当前占据代理。该模型仍需人物行为与漏检验收。 |
| 安全层再次缩速搜索 | 人物拒绝后，以更低速度重复预测。 | 删除第二次搜索。独立安全只终审 DWA 给出的一个速度，拒绝就请求停车。 |

运动参数移入 `navigation/planning/configs/motion.yaml`。其中 `performance_profile: teb` 是冻结历史参数的来源名称，不会加载 TEB 求解器，也不表示这些数值已经过实车验收。源码清理及验证记录见[本次核验](../../outputs/navigation/history/reports/current_algorithm_cleanup.md)。
