# 感知导航地图与控制历史

本页概述历史开发中研究过的方法，不作为当前运行参数或验收结论。当前实现见[环境地图](../perception/技术实现-环境地图与场景表示.md)、[路径规划](../navigation/技术实现-路径规划.md)和[局部控制与安全](../navigation/技术实现-局部控制与安全.md)。

历史地图研究包括逐体素自由背景、人物历史归属、分区高程、未知区域插值、跨进程融合以及按消费者范围裁剪。当前实现使用有界静态支持、独立人物圆和地面冲突层，不将未观测区域自动视为空闲。近场证据和静态先验仍分别保留来源与时效。

导航曾研究TEB、带时轨迹修正、滚动轨迹和时间重参数化；当前使用Hybrid A*空间参考及DWA速度选择。人物预测采用确定性世界系轨迹，独立安全复核候选与停车范围。`performance_profile: teb`只表示历史参数来源，不加载TEB求解器。

雷达和IMU默认使用各自消息时间，固定时差只在有明确校准来源与适用会话时使用。历史来源和当前传感器配置见[建图与定位](../perception/技术实现-建图与定位.md)。当前现场事项集中在[实机问题](../感知导航实机问题.md)。
