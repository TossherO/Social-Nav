# 感知导航离线开发记录

本页归档转入实机阶段前的离线开发结论与未完成诊断。当前入口为[实机问题](../感知导航实机问题.md)、[运行手册](../感知导航运行手册.md)及算法专题；不要将这里的旧bag计数自动提升为现场故障。

## 保留的算法与依据

- 当前地图使用整数高度覆盖、近场自由历史、有效静态自由支持和独立人物圆。地面变化按实际空间冲突暂停相关自由支持，无法确定影响范围时保留整体暂停。CPU与CUDA遵循相同规则。
- 地面支持半径六组同输入对照采用735次真实地图输入。0.55至0.75米在1453个固定反馈姿态上将未知阻挡40降至7，0.90米因冲突范围扩张新增17次阻挡。默认采用最小的同收益已测值0.55米；这些是地图几何结果，没有重新执行参考、DWA或车辆。
- 无地面回波的合成断面在0.55米下也可能被邻域地面支持跨过。可观测落差仍保留冲突；这不构成完整负障碍检测能力。现有7厘米拟合容差、15厘米高度变化判据和5次确认条件保留。
- DWA采用同次调用共享认证预算、检查次数上限、已通过区间复用与最多4轮GPU细分。输入过期等待新观察后按正常间隔重试，不沿用几何无路退避；取消、换图、重置和迟到结果保护保留。
- 人物点按同帧框与二维连通性归属，交给带速度的圆；背景射线仍止于实际回波。用户认可所选65帧动态审查，尚无独立逐点真值。

## 暂不主动推进的离线诊断

10月20日旧路线仍有约26.42–27.03秒的7份未知姿态，所有已测半径均未消除；89秒附近还有未取得归属依据的普通命中。此前地图版本的6份DWA预算退出保留原输入，尚未逐例延长诊断。旧bag不会执行减速，不能将超过常规限速时的无候选持续时间直接解释为真实执行失败。

10月29日旧先验的起点足迹同时受静态邻格高差和静态未知格限制。215个未知格次的保存子集中，111个来自高差、88个涉及11个静态未知格、16个在可信范围之外；不是当前新地图的通行性成绩。仅扩大高度容差或换中位数地面没有解决该子集，不默认重新开启这条优化路线。

单平面与最后内点写入、长期遮挡、静态背景变化、负障碍、坡道和换层缺少独立精度依据。后续若现场出现具体故障，再从当前观察验证，不把旧开发集全部重跑作为实机前置。

检测增量训练、独立人物标签和长期数据留出按[检测专题](../perception/技术实现-检测训练.md)及[数据与评测](../experiments/数据与评测.md)组织。VLM、Agent的自动调度与真实反馈分别由[系统方案](../系统方案.md)、[Agent计划](../decision/Agent技术开发计划.md)和[导航任务计划](../decision/长程导航任务与评测计划.md)维护，不进入人工目标试车的前置清单。
