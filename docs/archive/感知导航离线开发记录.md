# 感知导航离线开发记录

本页保留进入实机阶段前的算法与数据来源概览，不作为当前运行配置或实机验收。当前入口为[运行手册](../感知导航运行手册.md)，现场待处理事项由[实机问题](../感知导航实机问题.md)维护。

地图使用高度覆盖、近场自由历史、静态自由支持和独立人物圆；地面变化按空间冲突限制历史自由。DWA使用共享认证预算、检查次数上限、已通过区间复用和有界GPU细分。人员点以同帧检测与几何连通性归属，原始观测时间与身份对应关系保持不变。机制与适用范围见[环境地图](../perception/技术实现-环境地图与场景表示.md)和[局部控制与安全](../navigation/技术实现-局部控制与安全.md)。

地面支持半径的历史同输入对照、人物点归属审查和离线目标回放只用于开发，不代替独立障碍真值或现场执行反馈。数据与性能的来源、口径和适用范围分别见[数据与评测](../experiments/数据与评测.md)及[推理速度](../感知导航推理速度.md)。历史方案取舍见[地图与控制历史](感知导航地图诊断历史.md)。
