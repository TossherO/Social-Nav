# 感知导航操作速查

本页只保留当前问题。运行命令见[运行手册](感知导航运行手册.md)，RViz起点、目标和bag暂停操作见[交互测试](感知导航运行手册.md#rviz交互测试)。

- **近场仍可能受阻。** 静态未知、地面高差和漏分人物的普通占据仍会阻挡完整车体足迹；无图区域更依赖稀疏的16线雷达观测。不能用全局填空闲处理。见[地图诊断](感知导航规划诊断与改进.md)。
- **参考与DWA仍会中断。** 主要有等待新参考、旋转段衔接、足迹受阻、短时关联过期和少量无可行速度。常规运动参数与较快的录包运动也可能不匹配；激进配置仅保留为试验上限。见[失败溯源](感知导航规划连续性与失败溯源.md)。
- **耗时长尾仍需控制。** 个别候选碰撞检查较慢，部署设备的完整负载与长期运行还未验收。见[推理速度](感知导航推理速度.md)。
- **实机尚未验收。** 交互测试程序已有受控串口出口，但本车轮廓、外参、制动、固件失联保护和协议仍需确认。bag预览与模拟串口测试不能证明真实导航、到达或停车。

详细待办与采集需求统一维护在[共同清单](感知导航待办与数据采集.md)。
