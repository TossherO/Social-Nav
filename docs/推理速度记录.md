# 推理速度记录

本文按感知、导航、局部 VLM 和 Agent 保存最近可追溯的代表性记录。已保存结果来自不同版本与条件；当前代码尚未在相同现场条件下重新测速，不能据此推断最新性能或实机安全。

## 感知与导航

2026-11-09 轮椅端使用约 10 Hz 雷达、三帧 FP32 检测、18 米局部窗口和 10 Hz 地图目标频率；有地图、RViz 和目标请求，运行约 90 秒，安全为影子模式，轮椅未移动。901 张环境图按有效局部定位时间估算约 10 Hz；环境图处理 P50／P95 为 **11.74／13.96 ms**，源观察年龄为 **52.81／66.34 ms**。部分周期生成规划候选，另有规划不可用周期。数字来自此前的现场汇总；原始运行目录不在当前服务器，无法在此复核。

作为不同执行条件的参考，2026-11-08 轮椅端 RTX 4060 Ti 16GB 使用约 10 Hz 雷达、三帧检测、7.5 Hz 地图目标、二楼地图和 RViz，包含人工目标规划及独立 CPU 安全检查，不含 VLM 或 Agent。有效定位约 168.4 秒，1260 张环境图约 7.48 Hz。数字来自此前的运行摘要；原始文件不在当前服务器。

## 局部 VLM

2026-11-16 使用 10 月 23 日 bag 的两组三帧 RGB／BEV，通过托管 `qwen3.8-flash` 和 JSON Schema 约束检查两字段 T2 输出；两次完整返回分别约 **1.54／1.43 秒**。另以移除可选人物的模拟输入检查观察点选择，完整返回约 **1.41 秒**。三次格式均有效，输出分别为 13、13、14 token。请求含新连接和图像上传，服务硬件未知；模拟输入不证明真实丢失时的行为，少量样本不能评价在线识别或延迟分布，也不能代表 DSPARK 的性能。预览为未随 Git 提供的实验产物 `outputs/decision/t2_two_field_preview/index.html`。

## T2 本地身份匹配

2026-11-21 在开发服务器上以 RTX 3090、TensorRT FP32 原速回放 `follow1.bag` 前 29 秒。使用同一目标裁剪，将外层 Agent 的跟随图像改为按需生成后，T2 工作线程稳定阶段的墙钟耗时 P50／P95 从 154／214 毫秒降至 56／80 毫秒。控制线程尝试应用的结果从 69 个增至 99 个，源扫描到尝试应用的中位时延从 318 毫秒降至 219 毫秒。P95 从 417 毫秒升至 431 毫秒，超过 500 毫秒的结果从 3 个增至 5 个。按 RGB 和雷达源时间同时对齐的 62 帧上，中位时延也为 318 与 219 毫秒，P95 分别为 417 与 508 毫秒。一次较早的改后回放提前结束，具体原因没有保留下来。上述完整对照只衡量服务器回放，实际运动与轮椅端时延仍需测量。
