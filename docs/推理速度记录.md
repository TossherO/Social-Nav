作为不同执行条件的参考，2026-11-08 轮椅端 RTX 4060 Ti 16GB 使用约 10 Hz 雷达、三帧检测、7.5 Hz 地图目标、二楼地图和 RViz，包含人工目标规划及独立 CPU 安全检查，不含 VLM 或 Agent。有效定位约 168.4 秒，1260 张环境图约 7.48 Hz。数字来自此前的运行摘要；原始文件不在当前服务器。
