# 数据与评测

本文维护当前轮椅场景的数据划分与评测口径。操作见[决策标注](../decision/决策任务标注.md)、[VLM手册](../decision/VLM部署与调用.md)，待办见[系统方案](../系统方案.md#83-待完成工作)。本机最终结果由环境记录定位。

## 数据来源与划分

原始rosbag、定位／跟踪／二维关联结果、派生输入与人工标签分开保存，由[统一数据入口](../开发指南.md#数据入口与迁移)定位。冻结VLM不训练参数，检测训练的模型与数据划分独立登记。

按采集来源、重复地点及物理人物组织事件，先划分开发、验证、留出，再生成窗口或调整Prompt。相邻帧与同一事件不随机跨划分，重新切包不产生独立场景。未审核、未划分草稿可作明确标记的开发诊断，不能报告盲测精度。

输入保留采集时间、感知及RGB关联身份、当前PID映射、图像摘要和指纹。更换检测器、定位、关联或渲染后核对绑定，不修改旧摘要掩盖变化。原始数据、人工标签与模型默认只读。

## T1关系识别

人工先复核与模型相同的中性三帧RGB＋扫描BEV，区分成员／活动可判、未知及漏检覆盖。关系颜色、隐藏身份和未来证据不进入请求。

紧凑响应只列有支持的同行、交谈、拍照及其他共同活动，空对象不证明所有人已确认独行。标注中的未知、角色和参考组另存，不直接将富信息导出替代紧凑金标准。

分别报告整窗完全匹配、成员或带关系人物对指标、少数活动TP／FP／FN。说明人物对是否要求关系一致，保留漏组、错组及非法响应惩罚，不用大量同行样本掩盖其他类退步。

## T2身份与因果状态

固定事实包含描述来源、隐藏物理人物、可见性、真实对应、合理候选和覆盖。描述只来自初始可见证据，不含PID和未来细节；人工身份不用于事后修复模型输入。

先评估id/match，再评估带真实历史的id/state。visible需当前外观，occluded需此前确认及连续保持，uncertain拒绝不可靠身份，lost／not_found由本方法是否曾确认区分。不能把oracle历史当所有方法的统一五态答案。

| 范围 | 记录与限制 |
|---|---|
| 可见且有可靠PID | 身份命中、错选和拒绝确认；未重审草稿仅作诊断 |
| 无对应／原标签记为漏检 | 复核当前是否仍无候选，不自动当负例或错误身份 |
| 短遮挡 | 身份与当前可见状态分开，保持不刷新视觉时间 |
| 丢失后重新出现 | 核对轨迹生命周期key，记录恢复和失败，不能只比较PID数字 |
| 歧义、初始无目标 | 需要各自实例，不能由其他状态的合法输出代替验收 |

顺序回放只用过去接受的结果推进历史；预热不推进，非法结果终止该因果序列。原始响应保留，不修复或用真值重置历史。人工干预错误历史单列，不混作自然失败率。

## T3选点与就座阶段

分开评估候选生成、语义选择、几何验证与真实执行。人工粗略候选或`geometry=unknown`可用于开发输入与Schema，模型选中它不证明位置可达或就座完成；参考应允许多个可接受位置，候选召回与给定候选下的选择分别报告。

无解只针对本次候选集合，证据不足单列。演示终点可作后续姿态参考，不倒灌为早期输入或唯一答案。使用整段演示的桌边辅助拟合须标明证据截止时间，基本视觉对应、尺寸／真角点、净空和可达性分别复核。

阶段核心的合成反馈测试只验证状态和绑定逻辑。真实验收另需几何、导航、实际速度、连续保持及新鲜停止确认，分别记录到达误差、失败、取消与终止；离线Schema合法或单次演示不能替代。实现和联调待办见[VLM手册](../decision/VLM部署与调用.md#t3目标选择与就座)。

当前轮廓与三帧方案可作为闭环联调起点；观察位姿的预测视野覆盖不等于实拍可见性，bag原驾驶轨迹也不作为主动观察的成功反馈。单帧／三帧对照保持候选与当前图一致，先区分增加图像是否补充了视角，再评价选点收益；粗略轮廓及历史车体下的末姿态差不作为实机精度。

## 外层Agent导航任务

Agent 使用 VLM 选择导航位姿并审查任务，首轮独立于 T1、T2、T3，优先完备地图下的室内点、区域和串联任务。已有反馈仿真及少量 API 接入检查，尚无实车闭环成绩。研究依据见[Agent 技术开发计划](../decision/Agent技术开发计划.md)；三类地图、具体任务、基线、指标和仿真与实车的结论范围集中见[导航任务与评测计划](../decision/长程导航任务与评测计划.md)。

## 配对实验与保留

固定观察、Schema、模型与失败口径，一次检验一个因素。少量样本筛选后固定方案，在其他事件核对退步；同源时仍称开发迁移诊断。已有结果有效时不重复全套调用。

每任务集中保留最终报告、必要输入／参考、参数与原始响应。按明确授权清理旧实验前，先迁移最终结果所需依赖，保留原字节、摘要及标签来源，明确记录路径调整。

## 时效与导航价值

首token、完整返回和信息年龄分别统计，采集、定位、图像、HTTP开始及完成时间保持来源。按源时间推进的串行回放不证明实时0.5Hz执行，在线还需忙丢弃、超时、迟到接纳和任务／身份失效验证。

导航价值需同几何／感知条件下的行为对照，不能以合法JSON、关系F1、单段身份匹配或候选选择代替。受控实机运动另需足迹、运动学、本地安全与明确授权；当前T3离线原型不作为导航成功成绩。
