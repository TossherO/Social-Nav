# 感知操作速查

从仓库／客户端根目录按任务选用，**不整页顺序执行**。技术解释见[感知总览](感知总览.md)所链接专题；机器资源见[本机记录](../../ENVIRONMENT.local.md)。各次算法的输出子目录须尚不存在，训练命令另见[检测训练](技术实现-检测训练.md)。

ROS查询只针对终端当前连接的master；统一bag任务使用隔离master，外部终端不会自动连接，未设置对应ROS_MASTER_URI时读取保存产物。

## 准备

系统ROS终端先退出Conda；检测解释器单独指定。仅缺构建或相关源码变化时构建，`all`可换为`sensors/mapping/environment/interfaces`。

```bash
P=perception/scripts
source "$P/ros1_env.sh"
BAG=/path/to/recording.bag
MAP=/path/to/complete_map
ENV_MAP=/path/to/environment_package              # 与MAP绑定的静态环境包，先验视图可选
POSE="${BAG%.bag}.initial_pose.json"                # 与该bag、地图绑定的人工起点
OUT=outputs/perception/session_new                # 本轮产物根目录，重复运行时更换
RESULT=outputs/perception/previous_run            # 要回看的既有运行目录，也可填完整地图目录
PEOPLE_PYTHON=/path/to/detector/env/bin/python
export CUDA_VISIBLE_DEVICES=GPU_ID                # 运行检测或PIN前设置
```

```bash
BUILD_JOBS=2 bash "$P/build_ros1.sh" all
```

前三块分别在三个终端执行；录包先Ctrl+C结束，再停驱动。切包静态TF只能从原包补回，不能生成不存在的标定。

```bash

```

```bash
# 终端2：仅在真实设备采集时设置；外部bag模拟在线应使用下方模拟时钟配置。

bash "$P/start_sensors.sh" --serial-front FRONT_CAMERA_SERIAL
# 后视可加 --rear --serial-rear SERIAL；序列号可由本机配置提供。
# --lidar-only不提供FAST-LIO所需IMU。
```

```bash
# 终端3：保留一份RGB及其内参、原始点云、真实IMU和已有静态TF。
mkdir -p "$OUT"
rosbag record --lz4 -O "$OUT/capture.bag" /rslidar_points /camera/imu \
  /camera/color/image_raw /camera/color/camera_info /tf_static
```

```bash
# 查看包；图形浏览需已安装rqt_bag。
rosbag info "$BAG"
rqt_bag "$BAG"

# 只在外部master上模拟在线输入时使用；不要与统一bag任务同时向该master回放。
rosparam set /use_sim_time true
rosbag play --clock --pause -r 0.5 "$BAG"

# 按原包记录时间切出[10,20)秒；输出新文件，数值按需要修改。
mkdir -p "$OUT"
BAG_T0=$(/usr/bin/python3 -c 'import rosbag,sys; b=rosbag.Bag(sys.argv[1]); print(b.get_start_time()); b.close()' "$BAG")
rosbag filter "$BAG" "$OUT/cut.bag" "$BAG_T0 + 10 <= t.to_sec() < $BAG_T0 + 20"

# 切包缺/tf_static时，使用已提供的恢复工具；实际位置见本机记录。
TF_RESTORE=/path/to/restore_tf_static.py
SOURCE_BAG=/path/to/original_with_tf_static.bag
/usr/bin/python3 "$TF_RESTORE" --source "$SOURCE_BAG" \
  --input "$OUT/cut.bag" --output-dir "$OUT/cut_with_tf"
```

## 离线建图定位与检测

入口自建master／回放，无需额外启动。初值选项互斥，`--pose-file`须匹配bag、地图和起始偏移；只做定位时去掉检测参数。

```bash
# 建图：完成后地图位于该运行目录的map/；随后将MAP改为它。
bash "$P/run.sh" --mode mapping --bag "$BAG" --out "$OUT/mapping" --rviz

# 给bag保存起点：显示首帧点云与RGB，只选点，不运行定位；拒绝覆盖已有标注。
bash "$P/pick_start.sh" --bag "$BAG" --map "$MAP" --out "$POSE"

# 有图定位＋检测跟踪：使用已保存的起点。
bash "$P/run.sh" --mode localization --bag "$BAG" --map "$MAP" --pose-file "$POSE" \
  --people-python "$PEOPLE_PYTHON" --out "$OUT/bag_localization" --rviz

# 无图定位＋检测跟踪：不需要MAP或POSE。
bash "$P/run.sh" --mode odometry --bag "$BAG" \
  --people-python "$PEOPLE_PYTHON" --out "$OUT/bag_odometry" --rviz
```

## 统一场景与混合模式

以下查询连接当前master；场景ID取发布元数据。混合路线加`--association-coverage COVERAGE.yaml`启用边界门控，参数与范围见[定位技术文档](技术实现-建图与定位.md#手动地图可信区域与混合定位)。

```bash
bash "$P/run.sh" --mode localization --bag "$BAG" --map "$MAP" --pose-file "$POSE" \
  --environment --allow-local-only --scene --visual-memory \
  --prior-map "$ENV_MAP" \
  --association-coverage "$OUT/localization_coverage.yaml" \
  --people-python "$PEOPLE_PYTHON" --out "$OUT/scene_run"
# 需要光学相机位姿时显式添加同安装标定。
rosservice call /perception/scene/status
rostopic echo -n 1 /perception/scene
# 将SCENE_ID替换为场景中的observation_id；可额外绑定input_fingerprint。
rosservice call /perception/scene/query \
  'request_json: "{\"operation\":\"get_scene\",\"observation_id\":\"SCENE_ID\"}"'
# operation=get_rgb返回PNG/base64及像素摘要；几何操作为query_geometry／crop_map，须指定frame。
# 不需要先验视图时省略 --prior-map；配合 --rviz 显示可撤销的历史占据层。
# get_prior查看先验状态；query_prior_geometry／crop_prior_map要求frame=map。

# 停止后生成最后一份场景的中性决策视图；输出目录必须尚不存在，不调用模型。
"$PEOPLE_PYTHON" -B -m decision.vlm.environment_inputs --scene "$OUT/scene_run/scene" --out "$OUT/scene_run/decision_context"
# 旧场景可显式添加 --prior-map "$ENV_MAP" 生成新的三栏视图，不修改源场景。
```

```bash
# 同一批真实前端／配准到达事件，对比保留／屏蔽覆盖；比较实际公共状态与事件重放。
/usr/bin/python3 -B -m perception.mapping_localization.experiment \
```

## bag 行人中心标注

先predict，再open复核，最后export；不需要master／定位。可重复`--bag`添加子包；交互、划分和监督见[训练文档](技术实现-检测训练.md#rosbag人工中心复核与增量训练)。

```bash
ANNOTATION=data/annotations/rosbag_people/task_scene
ANNOTATION_GPU=0                             # 按本机空闲资源选择一张物理卡

# 创建工程，顺序检测全部扫描；同一工程可重复 --bag 添加多个来源。
bash "$P/annotate_people.sh" predict --bag "$BAG" --project "$ANNOTATION" \
  --detector-python "$PEOPLE_PYTHON" --gpu "$ANNOTATION_GPU" \
  --root-group ORIGINAL_RECORDING --location-group LOCATION --split train

# 打开／继续标注：窗口选择当前子 bag，只使用缓存／手工。
bash "$P/annotate_people.sh" open --project "$ANNOTATION"
# 可加 --sequence 子包文件名（或完整路径／来源ID）指定初始序列。
# 可加 --sample-interval 1 显式指定步长；省略则恢复各包设置，初次为1秒。

# 可选：导入有模型来源元数据的既有单帧候选；不把跟踪预测当标签。
bash "$P/annotate_people.sh" open --project "$ANNOTATION" \
  --detections /path/to/observations.jsonl

# 先查看默认选择（待标＋已标）的样本数及实际点云数；不读取bag。
bash "$P/annotate_people.sh" export --project "$ANNOTATION" --history-frames 3 --dry-run

# 关联已有定位并导出：当前点云＋3帧历史、当前RGB、核验中心；不启动训练。
bash "$P/annotate_people.sh" export --project "$ANNOTATION" \
  --history-frames 3 --pose-results /path/to/recorded_results \
  --out data/datasets/wheelchair_det_extra/task_scene
# 省略--out时默认data/datasets/wheelchair_det_extra/<工程名>；已有目录仍拒绝覆盖。
# 默认--history-frames 0（单帧）；--complete-only仅取已标帧。
# 可加--sequence 子包名、--history-stride 2、--start 10 --duration 30。
# --pose-results按子包优先有图定位；省略时仅保留原始历史，不能直接拼接训练。
# 位姿默认只取过去20ms内状态；可用--max-pose-age调整；训练仍默认单帧。
# 默认缺RGB报错；确认接受缺图时加--allow-missing-images。
# 切包末尾配对窗需放宽时显式加--max-image-age 0.15（秒，仍只取过去图像）。
```

## 任务场景检测微调

在已准备的检测环境中执行；先选两张空闲卡。默认新增全用于训练、旧验证仅作回归诊断，策略见[训练实现](技术实现-检测训练.md#任务场景增量适配)。

已有准备好的配置可直接使用`train_wheelchair_task_scene.sh`，默认配置与参数见`--help`。下面同时列出新数据准备和显式指定配置的用法。
