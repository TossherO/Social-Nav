# Wheelchair 弱监督设计

本文维护标注语义、监督边界和方法依据。数据生成、编译与训练命令见[检测训练](检测训练.md)。已有三阶段、中心完整性监督和EMA已实现；双教师、双视图、持久化伪标签记忆及轨迹传播仍是可选研究设计，不将其当成当前能力。

## 1. 前提与总体结论

目标是在 CODA-16line 行人检测模型基础上，将模型迁移到 Wheelchair 室内场景，最终仅检测 `Pedestrian`。

当前能够使用的监督为：

1. CODA-16line 的完整 3D 行人标注，作为源域强监督。
2. Wheelchair 中由前视图像语义产生的伪 3D 框。
3. Wheelchair 中无法拟合 3D 框时保留的伪 3D 中心点。
4. 部分室内场景的人工 BEV `(x, y)` 行人中心点。
5. Wheelchair 其余无标签帧。

Wheelchair 端已经没有任何可信的完整 3D 真值，因此本任务不再是常规微调，也不是标准的“少量目标域全标注”半监督学习。推荐采用：

> CODA 源域持续强监督 + Wheelchair 人工中心弱监督 + 多来源一致性伪框 + EMA Teacher 自训练。

训练中必须保持两个边界：

- Wheelchair 人工点不能直接监督 `z/dx/dy/dz/yaw` 或 ROI box regression。
- 没有人工 BEV 补全的 Wheelchair 帧仍不能把未标注位置直接作为背景；但对已经
  人工复核的帧，人工中心与原始伪标签的并集近似穷举，可以提供目标域背景监督。

目标域没有完整3D真值，不能可信计算3D/BEV IoU AP或证明尺寸/朝向精度。穷举中心帧可计算中心Precision/Recall/F1；非穷举帧未匹配预测仍是待复核。结合点云支持、源域AP和人工可视化选择模型。

## 2. 已有数据的角色

### 2.1 CODA-16line：唯一的完整框监督

CODA 继续负责：

- 行人类别和背景判别。
- 3D 中心、高度、尺寸和朝向回归。
- VoxelRCNN proposal、ROI 分类和 ROI box refinement。
- 防止目标域弱监督训练导致检测器退化或输出大量假阳性。

因此领域迁移期间不能完全丢弃 CODA。混合适配阶段保留源域 batch；最后的短周期室内固化通过冻结几何/ROI回归保护源域能力，不要求继续采样CODa。

### 2.2 Wheelchair 人工 BEV 点：最高可信的目标域监督

`data/datasets/wheelchair_annotations/annotations_*` 中的人工 `(x, y)` 点应视为目标域最可靠标签，但它只能确定：

- 该位置附近确实存在一个 `Pedestrian`。
- 行人的 BEV 中心位置。

它不能单独确定：

- `z`、高度、长宽和 yaw。
- 原始伪框的 3D 几何是否正确。

标注协议已经进一步确认：在有人工 BEV 标注的帧中，人工中心只补充原始伪标签
漏掉的行人，因此二者并集基本无漏标。这一结论只赋予这些帧“中心/类别层面的
穷举性”，不提高原始伪框的 `z/size/yaw` 可信度。

标注键从 `0` 开始，但它表示主场景 pkl 中对应 `frames` 列表的零基下标；必须按
`annotation[k] -> frames[k].frame_index -> pointcloud` 映射，不能由点云起始编号
推断固定偏移。

### 2.3 图像伪 3D 框：候选框而非真值框

`wheelchair_infos_train_full_by_scene.pkl` 中约有 5.8 万个正尺寸伪 3D 框。这些框可以作为候选框池，但不能直接全部加入 GT：

- 图像语义分数衡量的是图像侧类别置信度，不等同于 3D 定位质量。
- 前视相机造成严重漏检。没有人工补全的帧中，未生成伪框的位置不能作为负样本；
  已人工补全帧则以“伪标签 + 人工中心”的并集确定完整正样本集合。
- 框的尺寸、深度和 yaw 可能由稀疏点拟合产生较大误差。

人工补标遵循互补规则：某个目标已有伪 3D 框时，不会再为它标注人工 BEV 点。
因此“某个框附近没有人工点”不是负面证据，人工点也不能用于修正、验证或降级
原有框。拥挤场景中相邻的人工点和伪框应视为两个不同目标，不能仅按中心距离
合并。

### 2.4 伪中心点：低权重正样本

约 4.1 万个没有有效尺寸的伪标注只能提供中心候选。即使图像分数很高，也不能说明其 3D 框可靠。它们只能用于：

- 低权重中心正监督。
- Teacher proposal 搜索的空间提示。
- 时序轨迹候选。

### 2.5 无标签帧

主伪标签 pkl 只包含约 4.1 万帧，而原始主数据约有 7.9 万帧。未出现在 pkl 中的帧应作为 `unlabeled` 输入 Teacher–Student 一致性训练，不能生成空 GT 后进行全图负监督。

## 人工复核中心协议

rosbag 标注工具采用与历史互补补漏不同的协议：模型只提供建议，人工确认／修正已有中心、删除误检并补充漏检，最终保存完整复核范围内的**唯一正样本集合**。被删除的建议不能在转换时重新并入，也不能降级为中心正样本；同一个被确认候选只对应一个人工中心，不按空间距离自动合并相邻行人。

- 原始雷达坐标，XY 单位米，绑定具体来源、话题、扫描序号、纳秒时间及输入指纹；不使用地图点或没有来源的位姿。
- 仅 `complete` 帧启用完整中心背景和 ROI 中心分类，零中心须人工确认无人；`unreviewed`、`draft`、`skipped`及不确定目标不能提供完整负监督。首版不支持局部复核区域的负监督掩码。
- 所有已确认中心按人工中心监督处理；占位 `gt_boxes`仅用于接口兼容，逐维回归掩码为 `[1,1,0,0,0,0,0,0]`。`is_target_domain=true`，关闭普通 ROI 框监督，由弱监督配置启用中心式 ROI 分类；占位高度、尺寸、朝向和原预测框均不是几何真值。
- 检测候选、拒绝记录与最终人工中心分开保存；晚返回的检测不得覆盖人工结论。显示降采样、Z 筛选及分数滑块不影响标签或训练点云。
- 完整性只覆盖约定模型范围。微调不得把未复核区域经旋转、缩放或平移带入训练范围后当背景；当前增量配置仅保留保持覆盖的镜像。

此协议不改变历史“伪标签＋人工补漏”的解释。新导出、历史弱标签和源域完整框必须按各自来源处理，不能用新的完整复核规则反向筛除历史伪标签。操作、数据划分和微调入口见[检测训练](检测训练.md#rosbag人工中心复核与增量训练)。

## 3. 统一标注结构

建议为 Wheelchair 目标增加逐维监督掩码，而不是把目标简单表示成“有框/无框”。

```text
name: Pedestrian
center_xy: [x, y]
box3d: [x, y, z, dx, dy, dz, yaw] 或空
supervision_type:
  manual_center       # 人工 BEV 点
  image_pseudo_box    # 原始图像伪框
  image_pseudo_center # 原始图像伪点
  teacher_box         # EMA Teacher 框
  fused_box           # 多来源一致后生成的框
quality: [0, 1]
cls_weight: float
box_code_mask: [x, y, z, dx, dy, dz, cos_yaw, sin_yaw]
roi_cls_weight: float
roi_reg_weight: float
source: manual/image/source_teacher/ema_teacher/track
```

每帧还应包含：

```text
scene_id
frame_index
unique_frame_id = scene_id/frame_index
lidar_path
sweeps
has_pose
label_is_exhaustive
heatmap_valid_mask
```

目标监督规则：

| 标签来源 | 中心 | z/尺寸/yaw | Dense 背景 | ROI 回归 |
|---|---:|---:|---:|---:|
| CODA 完整框 | 是 | 是 | 是 | 是 |
| 人工 BEV 点（未完成人工补全的帧） | 是，高权重 | 否 | 否 | 否 |
| 人工补全帧中的标签并集 | 是，按来源加权 | 否/仅可靠伪框 | 是，建议低权重起步 | 中心式分类可用，框回归否 |
| 原始伪中心 | 是，低权重 | 否 | 否 | 否 |
| 单一来源伪框 | 是 | 默认否 | 否 | 否 |
| 多来源一致伪框 | 是 | 按维度启用 | 小权重可靠区 | 仅最高等级 |
| 无标签帧 | Teacher 一致性 | Teacher 一致性 | 仅可靠背景 | 否 |

## 4. 两教师和候选框融合

建议保留两个不同角色的教师：

1. `source_teacher`：固定的 CODA-16line checkpoint，提供不会随目标域噪声漂移的初始 3D 几何先验。
2. `ema_teacher`：目标模型参数的指数滑动平均，逐步适应 Wheelchair 点云分布。

对 Wheelchair 人工点或伪中心，在附近收集 Teacher 和轨迹候选：

- `source_teacher` 的 3D proposal。
- `ema_teacher` 在弱增强下的 proposal。
- 相邻帧轨迹传播得到的中心/框。
- 局部点云的地面高度、框内点数和空间范围。

原始伪 3D 框是另一条独立监督流，只与其自身的图像分数、点云、时序以及
Teacher 结果做一致性检查，不与人工点进行匹配。

只有多个相互独立的信号一致时才生成 `fused_box`。推荐等级如下：

### A 级：可训练部分框回归

至少满足：

- 人工中心与 Teacher 中心距离在门限内。
- source/EMA Teacher 或 Teacher/原伪框在中心和尺寸上基本一致。
- 相邻帧中存在稳定轨迹或预测增强一致。
- 框内点数和尺寸合理。

处理方式：

- `(x, y)` 使用人工点。
- `z` 可由局部地面和高度先验得到；不稳定时屏蔽 `z`。
- 尺寸使用 Teacher 结果，并限制在 CODA 行人尺寸先验的宽范围内。
- yaw 只有在 Teacher、增强和时序结果稳定时才监督，否则屏蔽 yaw。
- 低权重训练 Dense box regression；ROI regression 初期仍关闭。

### B 级：仅中心监督

人工点、伪点，或只有一个可靠 proposal 的目标均属于此级：

- 监督类别和 `(x, y)`。
- 屏蔽 `z/size/yaw`。
- 不进入 ROI target assigner。

### C 级：忽略

不同来源明显冲突、尺寸异常、非有限值、没有点云支持或时序跳变的目标不参与监督。

在没有目标域完整框时，筛选策略必须追求高精度而非高数量。前几轮只使用一致性最高的一小部分伪框，再逐轮扩大；不要直接按图像 score 取固定阈值。

### 4.1 伪 3D 框过滤流水线

过滤是阶段 2 室内 EMA 自训练中的固定步骤，不增加新的训练阶段。每次伪标签库刷新都按以下顺序执行。

#### 第一道：硬合法性过滤

- 所有 box 数值必须有限，尺寸为正，中心在有效点云范围内。
- `bbox_3d` 已确认采用 `[x,y,z,dx,dy,dz,yaw]` 且 `z` 为几何中心。使用宽松的行人物理范围：高度 `0.6–2.4 m`、两个水平尺寸分别在 `0.15–1.5 m`。越界框不直接作为回归真值。
- 框内点数采用距离相关门限，近距离应有更多点，远距离不能使用相同的固定点数门限。建议从 `0–8 m: >=5`、`8–15 m: >=3`、`>15 m: >=1` 开始统计，再根据实际分布调整。
- 清除明显重复框。拥挤行人不能使用过强 NMS；优先按中心距离和多来源一致性保留或融合候选。
- 非法框若其自身伪中心仍可靠，应降级为 B 级中心监督，而不是删除后当作背景；人工中心始终由独立标签流处理。

#### 第二道：多教师一致性

- 人工点与伪框严格按互补目标处理；即使距离很近也不自动关联或跨类型去重。
- 将 Teacher 在翻转、旋转和缩放增强下的框变换回原坐标，检查中心方差、尺寸变化和 yaw 环形方差。
- A 级框初始可要求中心标准差 `<0.25 m`、尺寸相对变化 `<20%`，并且 source/EMA Teacher 的中心距离 `<0.5 m` 或 BEV IoU 达到宽松一致门限。
- 原始图像 score 只作为类别证据，其在综合质量中的权重不超过约 20%，不能单独决定框是否进入回归。

#### 第三道：点云和时序一致性

- 检查框内点数、点高分布、局部地面高度以及预测 z 是否合理。
- 原始伪框候选应在相邻 3 帧中的至少 2 帧出现；人工中心不参与该判断。
- pose 对齐后进行前后向轨迹匹配；使用较宽松的行人速度上限（初始约 `4 m/s`）排除瞬移框。
- 时序只能验证中心和尺寸稳定性，不能默认运动方向就是人体 yaw。

#### 输出分级

- A 级：通过硬过滤，并至少获得“原图像分数、双 Teacher、增强一致、时序一致”中的两个独立支持；允许低权重逐维 box regression。当前离线首轮具体要求图像分数不低于 0.6 且具有双向时序支持。
- B 级：中心可靠但几何不可靠；只监督类别和 `(x,y)`。
- C 级：中心本身也无法确认；完全 ignore。

第一轮没有目标域真值可校准绝对阈值，建议在不同距离段内按综合质量排序，只取最高约 20%–30% 候选作为 A 级，其余逐步降级。刷新伪标签库时记录 A/B/C 数量、距离分布和来源，若 A 级数量突然大幅增长，应视为 Teacher 自确认漂移，而不是自动认为模型已经改善。

## 5. 损失设计

推荐总损失：

```text
L = L_source_det
  + lambda_mc * L_manual_center
  + lambda_pc * L_pseudo_center
  + lambda_fb * L_fused_box
  + lambda_cons * L_teacher_student
  + lambda_temp * L_temporal
  + lambda_bg * L_reliable_background
```

建议起始权重：

- `lambda_mc = 1.0`
- `lambda_pc = 0.1–0.2`
- `lambda_fb = 0.1 -> 0.5`，随训练逐步增加，并再乘以目标 `quality`
- `lambda_cons = 0 -> 0.2`，前 5 个 epoch 线性增大
- `lambda_temp = 0.05–0.1`
- `lambda_bg <= 0.1`

这些值只能作为初始值。由于没有目标域 box GT，应优先选择更保守的伪框权重。

### 5.1 CenterHead

- CODA batch 完全沿用现有 CenterHead loss。
- 人工中心用固定小半径高斯产生正样本，只计算正位置及邻域的中心分类/偏移损失。
- 为回归 code 增加逐维 `box_code_mask`，允许只监督 `(x, y)` 或 `(x, y,z)`。
- 非穷举弱标注帧在未确认区域不计算普通负样本 focal loss。
- 人工补全帧在“人工中心 + 原始伪标签”以外的有效检测范围内计算背景 focal loss；
  建议目标域背景权重先从 `0.25–0.5` 起步，再根据中心 precision/recall 调整。
- 其余目标域帧的负样本仍只选取 source/EMA Teacher 在不同增强和相邻帧中都保持
  低响应、且远离任何人工点、伪点和轨迹的位置，并使用很小权重。
- CODA 分支持续提供完整的背景监督，可抑制“只训练正点”带来的全图高响应。

### 5.2 VoxelRCNN ROI Head

第一版方案中：

- ROI 分类和回归仅由 CODA 完整框训练。
- Wheelchair 人工点、伪点和普通伪框不进入 ROI loss。
- A 级 `fused_box` 稳定后，可用小权重训练 ROI 分类。
- 只有 source/EMA/时序三者均一致的最高质量框才允许训练 ROI regression。

这比用噪声伪框直接训练 ROI 更保守，但能避免第二阶段把不准确的尺寸和 yaw 进一步放大。

### 5.3 Teacher–Student

- EMA 动量建议从 `0.999` 开始。
- Teacher 使用弱增强，Student 使用强增强。
- Teacher box、人工点和伪中心必须通过同一增强矩阵映射到 Student 坐标系。
- 每 2–5 个 epoch 更新一次离线伪标签库，避免逐 iteration 伪标签抖动。
- 历史伪标签采用质量感知记忆：新预测只有在质量更高或多轮稳定时才替换旧框。

## 6. 时序策略

### 6.1 模型输入

默认使用单帧，多帧作为可选消融：

- 单帧：`MAX_SWEEPS=1`，源域与目标域一致，检验纯领域迁移效果。
- 4 帧、`MAX_SWEEP_TIME_LAG=0.35`：可选时序配置，覆盖约 0.3 s，需显式设置并选择匹配权重。

多帧融合仅在有可靠位姿或静止条件经明确确认时启用；缺位姿不自动推断静止。有 pose 场景使用 `inv(T_current) @ T_history` 对齐历史点。单帧不依赖该融合假设。

暂不把 8 帧作为主要配置。当前拼接只补偿自车运动，不补偿行人运动；0.7 s 时间窗容易产生行人拖影。

### 6.2 时序标签升级

- 在全局坐标系或当前帧坐标系建立中心轨迹。
- 使用距离门限、常速度 Kalman 模型和前后向匹配一致性过滤轨迹。
- 人工 BEV 点作为强轨迹锚点。
- 相邻帧 Teacher 结果稳定时，可将人工中心传播到邻近无标注帧，但监督权重随时间距离衰减。
- yaw 不能简单从运动方向获得：静止行人和侧向行走时，运动方向不一定等于人体朝向。
- 不能把当前框原样复制到历史帧。

## 7. 数据与输入域适配

### 7.1 类别和空间范围

- 所有配置只保留 `Pedestrian`。
- 第一版沿用 CODA-16line 的：
  - `POINT_CLOUD_RANGE=[-4.8,-9.6,-1.5,14.4,9.6,4.5]`
  - `VOXEL_SIZE=[0.05,0.05,0.2]`
- 该范围覆盖约 95.5% 的现有人工 BEV 点，并保持源 checkpoint 的网格结构兼容。
- 对超出范围的人工点只记录覆盖率，不要静默删除后仍按全部标注计算指标。

### 7.2 强度

Wheelchair intensity 约为 1–255，而当前 CODA-16line intensity 基本为 0。第一轮必须做两个对照：

1. Wheelchair intensity 除以 255。
2. Wheelchair intensity 置零，与 CODA 输入一致。

不得把 0–255 原始强度直接送入当前 VFE。若归一化强度方案明显更好，后续可在混合训练时对 CODA intensity channel 做随机置零，使模型不过度依赖传感器强度分布。

### 7.3 数据增强

- CODA 和 Wheelchair 使用相同的全局旋转、缩放和翻转约定。
- 人工点、逐维 box mask、Teacher 框和时序轨迹必须同步变换。
- Wheelchair 端暂不开启基于噪声伪框构建的 `gt_sampling`。
- 如果保留 CODA database sampling，只在 CODA 强监督分支使用，避免把源域稠密点外观直接粘贴到目标域后成为明显域线索。

## 8. 三阶段训练与课程

正式阶段为混合域适配、室内EMA/判别边界训练和室内固化，当前数据事实及采样/损失设计见第16节；实际默认轮数和命令由[检测训练](检测训练.md#单帧两卡三阶段训练)及脚本维护。

### 准备与基线

复用已确认的帧号、坐标和标签语义；仅数据变化或出现疑点时追加核对。按场景隔离人工补全验证帧，验证场景不进入训练或Teacher更新。源域source-only作为迁移前基线，记录中心指标、尺寸/点支持与CODa AP，单帧为默认，多帧仅作有目的的消融。

### 场景角色

| 层级 | 数据 | 用途与边界 |
|---|---|---|
| S | CODa-16line完整框 | 维持完整几何、背景及ROI能力，不直接代表室内分布 |
| W0 | Wheelchair室外/其他弱标注与无标签 | 传感器桥接，不决定最终室内边界 |
| W1 | 室内非穷举帧 | 场景覆盖与弱中心监督，不把漏标区域当背景 |
| W2 | 室内人工补全帧 | 穷举中心、低权重背景与中心ROI分类，不提供完整框回归 |

后续可研究阶段内提高室内比例、可靠时序传播、Source Teacher蒸馏或BatchNorm统计适配，但这些不是当前脚本的默认流程。升级伪标签需遵循第4～6节的一致性和监督边界；只在弱指标、可视化及源能力稳定后启用，不扩充新的训练阶段。

## 9. 模型选择与评估边界

### 9.1 可以计算的弱指标

- 人工点 `CenterHit@0.5m/1.0m`。
- 匹配预测的平均/中位中心误差。
- 同一轨迹上的中心、尺寸和置信度抖动。
- 预测框内的有效点数和非有限值比例。
- CODA 验证 AP 和 Recall。
- 对固定场景生成 BEV 可视化和视频，人工比较漏检、重复框和明显假阳性。

当前三阶段配置在 Wheelchair 链路中将最终 `NMS_THRESH` 设为 `0.2`，并使用
`CENTER_SCORE_THRESH=0.3` 计算中心指标。固定 checkpoint 的全量消融表明，原始
`0.01` 会过度抑制相距不足 1m 的行人；该修改只作用于最终后处理、验证和
EMA Teacher 输出，不改变 Student 的损失或 ROI 训练 proposal NMS。由于 CenterHit
是召回式指标，模型选择时必须同时查看 `PredictionCountOnLabeledFrames`。

### 9.2 不能从现有标签可靠得到的指标

- Wheelchair 3D/BEV AP。
- 目标域 precision 和每帧假阳性数。
- 尺寸、z 和 yaw 的真实误差。
- 最优伪框 IoU 阈值或真正的 target-domain checkpoint 排名。

因此，若完全不补标 3D 框，最终模型选择应同时满足：人工中心召回提高、时序稳定性改善、预测数量没有异常膨胀、CODA AP 没有严重下降，并通过固定场景人工可视化检查。单一弱指标不能作为最终依据。

即使不准备增加训练标注，仍强烈建议以后只为验证集补充少量完整 3D 框；这些框不参与训练，却能解决模型和阈值无法客观选择的问题。该建议不是本方案执行的前置依赖。

### 9.3 人工结果复核

操作入口、双视图及视频约定见[检测训练](检测训练.md#结果查看与对比)。复核使用相同输入点云、范围和坐标比例，区分人工中心、弱框及预测，不用历史拖影或预测点数代替真值。只有近似穷举中心验证帧可统计中心级假阳性；人工中心单独使用仍不足以计算precision。

### 9.4 最佳模型的断点恢复

Stage 2/3 的 `best_model.pth` 选择状态必须与模型、优化器和 EMA 一样跨进程重启
恢复，否则恢复后的第一次验证会把历史最佳值当作 `-inf`，并可能用更差模型覆盖
原有最佳模型。实现遵循以下规则：

1. epoch checkpoint 和 `best_model.pth` 均保存 `best_metric`、`best_epoch` 与
   `best_metric_name`；
2. 恢复时同时检查实际恢复的 epoch checkpoint 和输出目录中的
   `best_model.pth`，仅接受指标名称与当前配置一致的有限数值，并取其中较优者；
3. 每轮验证完成、最佳状态更新后再保存 epoch checkpoint，使 checkpoint 中的
   选择状态与该 epoch 完成时一致；
4. 老 checkpoint 缺少这些字段时保持兼容，按“尚无可恢复最佳指标”处理并记录
   日志，不影响模型与优化器恢复；
5. 回归测试覆盖“恢复值高于当前验证值时不得覆盖 best_model”和“新结果确实更优
   时更新元数据”两条路径。

正式流程只保留四个必须产出的 checkpoint：

|---|---|---|

## 12. 已确认的数据语义与保留假设

### 12.1 人工标注帧号

人工标注键`k`表示同场景`wheelchair_infos_train_full_by_scene.pkl`中`frames`列表的零基下标：

```text
raw_frame_index = scene_entry['frames'][int(k)]['frame_index']
```

生成器先载入主场景帧顺序，再解析人工标注；场景缺失、下标越界、场景或原始帧号重复时直接报错。模型与训练输入的对应关系以来源记录为准。

### 12.2 原始伪框格式

`bbox_3d`为`[x,y,z,dx,dy,dz,yaw]`，`z`表示几何中心，`dz`表示高度；垂直范围为`z±dz/2`。

### 12.3 仍采用的保守假设

1. 仅“人工 BEV 中心 + 同帧原始伪标签”的并集具有近似穷举性；人工中心单独使用、
   或没有人工 BEV 标注的帧，仍按非穷举标注处理。
2. `ref_size`不单独作为可信回归监督。
3. 当前过滤不使用2D／3D投影一致性，前视相机之外的区域不作为背景。

## 13. 方法依据

- [ST3D（CVPR 2021）](https://openaccess.thecvf.com/content/CVPR2021/html/Yang_ST3D_Self-Training_for_Unsupervised_Domain_Adaptation_on_3D_Object_Detection_CVPR_2021_paper.html)：源域到无标签目标域的质量感知伪标签记忆和课程式增强。
- [3DIoUMatch（CVPR 2021）](https://openaccess.thecvf.com/content/CVPR2021/html/Wang_3DIoUMatch_Leveraging_IoU_Prediction_for_Semi-Supervised_3D_Object_Detection_CVPR_2021_paper.html)：使用 IoU/定位质量而不是只依赖分类分数筛选伪框。
- [HSSDA（CVPR 2023）](https://openaccess.thecvf.com/content/CVPR2023/html/Liu_Hierarchical_Supervision_and_Shuffle_Data_Augmentation_for_3D_Semi-Supervised_Object_CVPR_2023_paper.html)：对不同可靠度伪标签采用层级监督。
- [NoiseDet（ICCV 2023）](https://openaccess.thecvf.com/content/ICCV2023/html/Chen_Learning_From_Noisy_Data_for_Semi-Supervised_3D_Object_Detection_ICCV_2023_paper.html)：面向分类和定位噪声的软监督与一致性训练。
- [WS3D（ECCV 2020）](https://www.ecva.net/papers/eccv_2020/papers_ECCV/html/1956_ECCV_2020_paper.php)：BEV 中心点击弱监督。本文原方法使用少量完整框，本项目以 CODA 源域完整框提供几何学习，并对 Wheelchair 回归采取更保守的掩码。
- [Back to Reality（CVPR 2022）](https://openaccess.thecvf.com/content/CVPR2022/papers/Xu_Back_to_Reality_Weakly-Supervised_3D_Object_Detection_With_Shape-Guided_Label_CVPR_2022_paper.pdf)：通过中心位置和形状先验补充真实场景中的弱监督。
- [DetMatch（ECCV 2022）](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136700366.pdf)：使用 2D/3D 教师预测一致性提高伪标签精度，可用于前视相机覆盖区内的质量检查。

## 14. 当前代码实现边界

当前实现包括：离线伪框硬过滤与降级、人工中心/伪框互补监督、
双向时序支持、CODA/Wheelchair 固定比例混合、未知背景屏蔽、逐维 Dense 回归
掩码、目标域 ROI 屏蔽、EMA 中心邻域升级、中心弱评估，以及阶段 3 的几何/ROI
显式冻结。EMA checkpoint 可以保存和恢复，多卡 rank-0 验证带同步屏障。

人工补全帧的穷举背景、分层采样、中心Precision/F1和目标域ROI中心分类已启用；生成器分别保留 `center_label_is_exhaustive` 与 `is_target_domain`，不能根据完整性推断数据域。对应YAML与实现是当前参数来源，第16节保留设计依据。

当前配置保持`ALLOW_UNMATCHED=false`，Teacher围绕已有人工／伪中心锚点升级监督；无标签帧不作为负样本，单次Teacher预测不创建无锚点正样本。

## 15. 多卡动态体素显存优化

动态点数和体素数量会造成多卡显存差异。当前优化包括：

1. CUDA 设备绑定必须早于 NCCL process group 初始化，避免所有 rank 先在逻辑
   GPU 0 建立上下文。
2. EMA Teacher 生成并注入伪标签后，立即释放其 `batch_dict`、预测和 head 缓存，
   避免 Teacher 稀疏特征与 Student 训练图同时驻留。
3. `DynamicVoxelVFE`执行数据配置中的`MAX_NUMBER_OF_VOXELS`。
   训练／测试分别使用配置中的`train`／`test`上限；超过
   上限时使用坐标哈希做确定性、无空间前缀偏置的选择，使 Teacher 与 Student 对
   同一输入保留一致的体素集合。
4. 提供可选的逐 rank 诊断日志，同时记录点数、限流前后体素数，以及 CUDA
   allocated/reserved/peak memory。诊断默认关闭，避免日常训练引入额外同步；可由
   `--log_gpu_memory` 或三阶段脚本的 `LOG_GPU_MEMORY=1` 开启。

实现保持未超过体素上限的数值路径，不逐iteration清缓存；仅在相关行为变动时运行体素限流测试，避免把专项诊断变成每次训练的固定开销。

## 16. 人工补全帧的精度优先设计

以下保留修订依据与候选实验参数；当前已启用的完整性分层、背景监督与中心ROI分类见第14节，实际阈值及轮数以训练YAML/脚本为准，不把历史建议全部列为待实现事项。

### 16.1 数据事实与语义

40 个室内人工标注场景共有 9,705 个已复核帧和 21,984 个人工中心；所有标注键
都至少包含一个 `Pedestrian`。这些帧中还有 17,145 个原始 Pedestrian 伪标签中心，
中心数值全部有限；现有预处理在伪标签来源内部去重后保留 17,126 个。因此两种
来源合并得到 39,110 个中心目标：训练集 8,486 帧/34,049 个目标，验证集 1,219
帧/5,061 个目标。

对这些帧应采用以下语义：

- `center_label_is_exhaustive=True`：并集之外的有效 BEV 区域可以训练为背景。
- `is_target_domain=True`：它仍是 Wheelchair 目标域，EMA 和域采样逻辑不能根据
  `label_is_exhaustive` 推断域。
- 人工中心只监督 `x/y`；伪中心监督类别和 `x/y`；只有通过现有几何、点数、分数
  和时序过滤的伪框才低权重监督 `z/size`，yaw 继续关闭。
- “中心标签完整”不等于“3D 框完整”，不得开启常规 IoU ROI 回归。

数据生成器应额外输出：

```text
wheelchair_weak_infos_train_indoor_exhaustive.pkl      # 8,486 帧
wheelchair_weak_infos_train_indoor_non_exhaustive.pkl  # 其余室内训练帧
wheelchair_weak_infos_val_indoor_exhaustive.pkl        # 1,219 帧
```

完整性必须依据人工标注文件中是否存在该帧键判断，不能依据合并后目标数量或
`weak_centers` 是否为空反推。当前数据恰好没有空人工标注键，但 schema 不应依赖
这一偶然条件。

### 16.2 损失与模型头

Dense Head 对三类样本分别处理：

1. CODA：保持原始完整 heatmap、box regression 和 ROI 监督。
2. Wheelchair 穷举中心帧：整个有效 heatmap 开启背景监督；人工正样本权重 1.0，
   伪标签类别权重建议由图像分数裁剪到 `0.5–1.0`，目标域背景权重从 0.25 起步。
3. Wheelchair 非穷举帧：维持当前正目标邻域 mask，未知区域不产生负梯度。

`CenterHead` 分别维护背景有效权重和每目标 `gt_cls_weights`，避免开启穷举背景时
把低置信伪标签提升为权重 1.0。修改该分支时保持两类权重独立，不能恢复为无条件全1 mask。

VoxelRCNN 最终分数来自 ROI 分类头，仅改善 Dense heatmap 不一定能充分消除最终
误检。因此在穷举中心帧上增加**中心式 ROI 分类**：proposal 中心到任一并集中心
距离不大于 0.5 m 记为正样本，不小于 1.0 m 记为负样本，中间区域 ignore；只训练
ROI classifier，不训练 ROI box regression。阈值应先在验证集检查，拥挤场景中
按一对一匹配避免多个 proposal 共享一个正目标。非穷举帧继续完全屏蔽目标域 ROI
监督。

### 16.3 修订后的三个训练阶段

阶段数量保持为三，不增加额外 Stage 4：

1. **阶段 1：源域与全量目标域适配（10–15 epoch）**
   - 约 50% CODA、50% Wheelchair 全量数据。
   - 继续学习传感器/点云分布差异；非穷举帧只提供正样本和 EMA 几何升级。
   - 穷举帧可以启用低权重 Dense 背景，但暂不开 ROI 中心分类，避免初始域差导致
     大量 proposal 被过早压制。
2. **阶段 2：室内判别边界训练（15–20 epoch）**
   - batch 建议固定为 25% CODA、50% 室内穷举帧、25% 室内非穷举帧。
   - 穷举帧同时训练 Dense 背景和 ROI 中心分类；非穷举帧保留 EMA 正监督；CODA
     维持可靠 3D 几何和常规 ROI 能力。
   - 这是降低墙面、门框和静态结构误检的主阶段，不再以扩大 Teacher 正标签数量
     为主要目标。
3. **阶段 3：室内精度固化（3–5 epoch）**
   - 100% 使用室内穷举训练帧，学习率 `3e-5–1e-4`。
   - 冻结 `z/dim/yaw` 和 ROI box regression；更新 VFE/backbone、Dense 分类/xy
     以及 ROI classifier。
   - 背景权重可由 0.25 提高到 0.5；只在 precision 仍明显不足且 recall 稳定时
     尝试 1.0。

阶段 2 需要三路固定比例采样。若暂不扩展采样器，可先用“25% CODA + 75% 室内
穷举帧”的双路版本验证核心假设，但正式方案应保留 25% 非穷举室内帧，以免牺牲
场景覆盖和稀有姿态召回。

### 16.4 评估、阈值与停止准则

验证只使用按场景隔离的 1,219 个穷举中心帧。对“人工中心 + 原始伪标签中心”并集
与预测中心做 0.5 m 一对一匹配，至少报告：

- `CenterPrecision@0.5m`、`CenterRecall@0.5m`、`CenterF1@0.5m`；
- 每帧 FP、每帧预测数，以及近距 `<=8m` 和远距 `>8m` 分层指标；
- 固定 score 阈值 0.3 的指标和完整 PR 曲线；
- CODA Pedestrian AP/Recall，监控 3D 几何能力是否退化。

以重构前 Stage 3 checkpoint 的 `score>=0.3`、`NMS=0.2`、当前帧点数过滤结果
作为 A0 基线，验证范围内有 4,918 个并集中心和 8,519 个预测：
`Precision@0.5m=55.86%`、`Recall@0.5m=96.77%`、`F1=70.83%`、
`FP/frame=3.08`。这确认此前仅看人工中心召回会严重低估误检问题，也为新训练提供
了可复现的精度基线。

最佳 checkpoint 不再只按当前 `CenterHit` 召回选择。优先使用
`CenterF1@0.5m`；若部署更重视安全召回，则使用“CenterRecall 最大且
CenterPrecision 不低于预设下限（例如 90%）”的约束指标。最终 score 阈值从
验证 PR 曲线选择，`NMS_THRESH=0.2` 保持不变。

### 16.5 最小消融顺序

按单变量顺序验证，避免一次改动过多后无法归因：

1. A0：现有 Stage 3 checkpoint，统一用穷举中心并集重新评价。
2. A1：只开启穷举帧 Dense 背景监督。
3. A2：A1 + 阶段 2 的穷举帧过采样。
4. A3：A2 + ROI 中心分类。
5. A4：A3 + 3–5 epoch 精度固化。

只有 A1 已能明显降低 FP/frame 且召回基本不降，才继续 A2/A3；若 A3 使拥挤场景
召回下降，优先放宽 ROI 正/负距离间隔，而不是降低最终 NMS 阈值。
