# 后续开发测试汇总

本页记录仍需开发或验证的工作。现场已观察到的问题及本车运行配置见[系统实机问题](系统实机问题.md)；已实现机制与操作分别见[系统总览](系统总览.md)和[系统运行手册](系统运行手册.md)。

## 感知与地图

- 在不同光照、遮挡、人流及楼层中验证检测、三维跟踪、定位和二维关联。IMU 时间异常、地图关联稳定性和实车性能以现场记录为准。
- 验证人工修正静态图、动态行人清除、局部未知区域及地面冲突的实际效果。静态空闲与人工编辑不是当前观测，不能替代局部地图。
- 按采集来源、地点及物理人物划分开发、验证和留出数据，避免相邻帧或同一事件跨划分。草稿、伪标签、未标注区和人工金标准分别记录。

## 导航与安全

- 在现场检查目标到达、路径重规划、狭窄区域未知格、DWA 可行候选与停车连续性。具体故障和试车优先级集中在[系统实机问题](系统实机问题.md)。
- 跟随或搜索目标过期时，核对参考路径的撤下时间、交给 DWA 的路径和规划记录。短时丢帧后，核对恢复使用的参考仍有有效目标和新的定位观测。
- 确认固件失联、串口中断、看门狗、人工接管及实际停车响应。当前有限时域检查不能证明完整制动过程安全。
- 用同一地图与几何条件比较算法收益，分别记录候选计算、提前退出、完整反馈和人工干预；离线 bag 或影子规划不代表实机完成。

## 局部 VLM

- T1 已有与观察对应的内存请求接口，连续调度和现场群组更新仍待接入。T3 已接入当前 RGB 桌沿范围、同源扫描选点、接近路径检查和导航反馈。用真实桌边样本分别核对目标桌身份、浅色与深色桌面、局部遮挡、无可达候选、目标过期和实际停稳。
- T2 已接入三帧采集、持续调度、选人及有限范围的搜索，已有合成联动和模拟模型的短 bag 影子检查。含人物的无图影子回放中，跟随目标已生成但参考路径未能生成，起点车体轮廓非空闲及路径搜索失败需结合有效地图进一步核查；原速回放亦有数据积压导致结果过期。需使用实际 DSPARK 服务和现场数据检查结构化输出约束、识别、遮挡、纠错、找回及耗时；当前搜索缺图时只能等待，远于搜索范围的最后位置无法直接到达。
- T1 需分别检查成员与活动、错组漏组和未知覆盖；T2 需区分身份、可见状态、覆盖和历史因果性；T3 分开评估候选召回、语义选择、几何可行和真实执行。保留原始响应，不修复或借助未来标签。

## Agent 与长程任务

- 完备地图下，运行时把任务要求、实际位姿、路线测量和有效观察直接交给执行 Agent，末段满足条件后自动收尾。现场重点检查模型响应期间再次移动、停稳估计失效、中途取消和人工接管，确认旧证据无法推进下一段。
- 人工乘梯按独立 RGB 与局部雷达观察进出，出梯后在等候区根据目标地图与实测扫描选初值。现场覆盖不同停车姿态、首次配准失败后重选、恢复定位后继续同一任务。T2 人工预览和 T3 桌边停靠需分别验证，再做跨层组合。简单图、无图和 T1 组合仍待开发。[人工驾驶测试方案](有图长程任务人工驾驶测试方案.md)
- 扩充独立指令，对照关闭思考、仅规划思考和全程思考。分别记录首次登记的字段错误、单点与多点工具混用、绕行中间点拒绝原因、首 token 和完整响应时延。完成决策另计漏判、无依据推进、等待、澄清及介入。T2 瞬时动作还要核对动作帧人物身份和随后停车是否属于同一调用。单条合成绕行指令的真实 API 抽查已覆盖首次登记和路线提交，结果及适用范围见[Agent 技术实现](decision/技术实现-Agent长程导航.md#服务配置与思考模式)。
