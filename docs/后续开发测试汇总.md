# 后续开发测试汇总

下一轮在实机端排查和修改。优先跟进二楼行人跟随、一楼局部环境图超限、二楼地图关联恢复，以及跨楼层的任务推进。现场现象、配置和代表性会话统一记录在[系统实机问题](系统实机问题.md)，操作入口见[系统运行手册](系统运行手册.md)。

## 优先复测的现场问题

| 问题 | 本轮需要确认的结果 |
| --- | --- |
| 二楼 T2 行人跟随 | 先用两份演示 bag 核对最新的规划切换、占据目标替代和遮挡找回，再进行人工驾驶验证。按同一观察的时间戳核对选人、请求耗时、规划和轨迹；最终检查任务结束动作与停稳证据。[现场记录](系统实机问题.md#时效与现场观察) |
| 一楼局部环境图超限 | 体素上限已按离线对照提高，同步和异步更新均通过单次超限恢复回放。沿等候区到大厅复测环境图更新和参考路径；若现场再次触发超限，核对故障时间、窗口和重新规划结果。[地图与定位](系统实机问题.md#地图与定位) |
| 二楼地图关联短时失效 | 对齐匹配质量、关联年龄和局部定位状态，找出首次失效原因。同图恢复后用新定位及停稳证据复核当前阶段。独立 ROS 诊断已用二楼短 bag 验证自动覆盖和显式覆盖均可完成配准，可用于补查匹配记录。[地图与定位](系统实机问题.md#地图与定位) |
| 到达后自动推进或等待口令 | 对照连续出发与明确要求等待的两条指令，核对二楼到达及一楼定位恢复后的模型工具调用、停稳证据和阶段切换。[任务监控记录](系统实机问题.md#时效与现场观察) |
| 乘梯与出梯定位 | 复测一楼标准点成功、失败或 30 秒超时后转人工选点，以及无标准点楼层的重选。取得目标楼层有效关联后恢复原任务，并按目标楼层的完成区域判断。[电梯与楼层切换](有图长程任务人工驾驶测试方案.md#电梯与楼层切换) |
| 桌边接近与通道预览 | 合成样本已分别核对参考路径先行绕开、局部绕行和未知带阻断。现场结合真实桌沿、障碍和接近路径核对规划结果。[规划与控制待验证项](系统实机问题.md#规划与控制待验证项) |

## 其他开发与验收

- **Agent 与局部决策。** 比较任务登记和执行的思考设置、工具参数、误判与耗时。继续验证有序多点、普通单圈绕行、视觉条件和中断后的阶段恢复。T1 连续调度、简单图和无图长程任务仍待开发。T1／T2／T3 离线评测应区分人工金标准、草稿和未标注数据，按地点、采集来源和人物划分。[Agent 技术实现](decision/技术实现-Agent长程导航.md) · [VLM 局部决策](decision/技术实现-VLM局部决策.md)
- **现场地图与感知。** 核对一楼新标注、二楼人工修正的空闲格与拟合高度，复核起点足迹、雷达地面高度初猜、不同光照和人流下的跟踪，以及 IMU 和显示变换异常。[地图与定位](系统实机问题.md#地图与定位)
- **规划、控制与接管。** 在半开门、狭窄通道、终点和换向处检查路径切换、扫掠、低速响应与实际停稳。结合现有独立安全、串口和接管记录核对停车原因与底盘反馈。[规划与控制](系统实机问题.md#规划与控制待验证项) · [导航与执行](系统实机问题.md#导航与执行)
- **T3 与组合任务。** 桌边连续观察和逾期拒绝已通过服务器回归。现场核对不同桌面、遮挡和无可达候选时的桌沿、接近路径与实际停靠。分别验证人工 T2、T3 后，再验证包含相应技能的跨层连续任务。[人工驾驶测试方案](有图长程任务人工驾驶测试方案.md)
