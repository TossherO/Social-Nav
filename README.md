# Social-Nav

Social-Nav 面向移动机器人和智能轮椅的长程社交导航。感知模块提供自车位置、行人轨迹和环境地图，决策模块理解任务与场景，导航模块规划路径并选择运动速度。本地安全监督独立检查每次运动建议。

当前感知导航以轮椅实机测试为主。支持rosbag、在线传感器和RViz交互，受控串口出口由独立安全监督授权。几何、倒车及原地旋转能力已确认，基本动作已有现场证据，完整目标导航仍需现场验证。当前工作从[实机问题](docs/感知导航实机问题.md)进入。

## 从哪里开始

第一次了解项目，先读[系统方案](docs/系统方案.md)，再用[开发指南](docs/开发指南.md)准备环境和资源。需要运行感知或导航时，读[感知导航总览](docs/感知导航总览.md)，然后到[运行手册](docs/感知导航运行手册.md)查找命令。

修改跨模块数据前，查阅[接口约定](docs/接口约定.md)。它解释坐标、时间、身份和失效处理，避免把不同观察的数据混在一起使用。开发规则由 [AGENTS.md](AGENTS.md) 维护；机器路径、解释器和已执行检查保存在被 Git 忽略的 [ENVIRONMENT.local.md](ENVIRONMENT.local.md) 中，新机器需要自行建立该记录。

## 当前能做什么

| 模块 | 已有实现 | 尚未完成的主要工作 |
|---|---|---|
| 感知 `perception/` | 传感器标定、检测训练与人工标注、建图定位、行人检测跟踪，以及供导航和决策使用的环境表示。 | 已用 bag 和模拟在线输入验证；仍需独立场景、长期运行和实机验收。 |
| 局部决策 `decision/vlm/` | T1 识别社会关系，T2 匹配并持续核对跟随身份，T3 选择目标并组织就座阶段。另有 T1、T2 标注工具。 | 离线开发与局部接口已有结果，自动在线调度、真实导航反馈和独立任务验收仍需完成。 |
| 外层 Agent `decision/agent/` | 单 VLM 原生工具调用和累积对话，完备地图下的点与区域要求、连续位姿选择、多图输入、完成检查及反馈仿真和 runtime 影子接口。 | 实车执行反馈尚未接通；简单地图、无图与主动移动观察保留为后续开发。 |
| 导航 `navigation/` | Hybrid A*参考、DWA速度、独立CPU安全，以及RViz交互与显式实机串口出口。 | 改善持续可用性，确认车辆参数、协议与硬件保护，完成部署端和实机验收。 |

`runtime/` 将感知和导航组织在同一套运行流程中。核心计算通过原生接口、共享内存和 GPU 数据引用连接，ROS 只用于传感器接入和可选显示。模块登记在 [configs/system.json](configs/system.json)，该文件不负责启动整机。

局部 T1、T2、T3 优先调用自有服务器上的 SGLang＋DSPARK；本地备用的适用条件见 [VLM 手册](docs/decision/VLM部署与调用.md)，当前 T3 入口只支持远程调用。外层 Agent 独立使用 Qwen3.8-Flash 托管 API，说明见 [Agent 技术实现](docs/decision/Agent技术实现.md)。

## 文档维护与历史资料
