# 导航域

全部为占位，没有可运行机器人节点。

## 模块职责

- `planning/`：全局路线/路径、局部轨迹、社会代价融合、跟随目标和停靠候选的几何生成。输入为真实定位/地图/轨迹、任务意图及有效VLM结果；输出可验证的路径/轨迹。
- `control/`：跟踪规划轨迹、限速/平滑、底盘指令适配及运动反馈。驱动模型/足迹/制动参数待测，暂不固定为Ackermann或差速。
- `safety/`：独立碰撞/制动/超时/急停监督，不能依赖远程VLM或agent在线。

## 安全与接入边界

规划与控制分开：语义模型不能直接输出连续速度；agent也不能绕过规划和安全。
静态占据/足迹碰撞优先于社会软代价；没有可行安全轨迹时停止。
Smac/Hybrid A*、MPPI、Nav2、ROLL、Collision Monitor等是旧方案候选，尚未选择或接入。
不启动ROS，不安装Nav2，不运行模拟成功节点，不宣称闭环安全已完成。
